## LOBSTR Mobile Wallet

For mobile users, [LOBSTR](https://lobstr.co/) provides a dedicated Stellar mobile wallet alongside its web and browser extension experience.

- **Platform availability:** Available on **iOS** ([Apple App Store](https://apps.apple.com/app/id1404357892)) and **Android** ([Google Play Store](https://play.google.com/store/apps/details?id=com.lobstr.client)), as well as via the web app at [lobstr.co](https://lobstr.co/).
- **Connecting to Nextellar dApps:** Mobile users can connect their LOBSTR wallet to a Nextellar app using [WalletConnect](/docs/integrations/walletconnect) or the LOBSTR browser extension on desktop.
