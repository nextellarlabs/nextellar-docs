# Building a Receive QR Page

A receive page with a QR code lets users share their Stellar address with others without manual copying or typing. This guide covers QR code generation, address encoding formats, Stellar payment request extensions, and a minimal working example.

---

## Address Encoding

The QR code typically encodes a Stellar URI that follows the [SEP-0021](https://github.com/stellar/stellar-protocol/blob/master/core/cap-0021.md) standard:

```
stellar:GBBD47UZT552PLLY7TSVVSQYUVJQJLAN47DDIUGACVM87DCAGYIPTU5
```

This is a bare address URI. For a complete receive flow, you can include optional parameters:

```
stellar:GBBD47UZT552PLLY7TSVVSQYUVJQJLAN47DDIUGACVM87DCAGYIPTU5?amount=100.50
```

### Stellar URI Scheme

The Stellar URI scheme allows clients to construct rich payment requests:

- **`address`** (required): The receiving account's public key
- **`amount`**: Optional; units in XLM or issued assets
- **`memo`**: Optional; memo string or ID to associate with the payment
- **`memo_type`**: Optional; `text`, `id`, `hash`, or `return` (defaults to `text`)
- **`label`**: Optional; human-readable name for the receiver
- **`message`**: Optional; payment reason or description

### Example: Rich Receive URI

```
stellar:GBBD47UZT552PLLY7TSVVSQYUVJQJLAN47DDIUGACVM87DCAGYIPTU5?
  amount=50&
  memo=invoice-123&
  memo_type=text&
  label=Acme%20Corp&
  message=Payment%20for%20services
```

## Payment Request Extensions

Several payment-related specifications extend the base Stellar URI:

### SEP-0023: Hosted Stellar Anchors

If you operate an anchor, use [SEP-0023](https://github.com/stellar/stellar-protocol/blob/master/ecosystem/sep-0023.md) to request payments in specific assets:

```
stellar:GBBD47UZT552PLLY7TSVVSQYUVJQJLAN47DDIUGACVM87DCAGYIPTU5?
  amount=100&
  asset_code=USDC&
  asset_issuer=GBBD47UZT552PLLY7TSVVSQYUVJQJLAN47DDIUGACVM87DCAGYIPTU5
```

### SEP-0024: Hosted Deposit and Withdrawal

SEP-0024 defines interactive deposit and withdrawal flows. If your receive page is part of a larger deposit flow, link to the SEP-0024 interactive endpoint alongside the QR code.

---

## QR Code Generation

Use a well-maintained QR code library to encode the URI. Popular options:

- **[qrcode.react](https://www.npmjs.com/package/qrcode.react)** (React) — Simple, declarative, supports canvas and SVG rendering
- **[jsqr](https://www.npmjs.com/package/jsqr)** — Lightweight, decoder included for scanning
- **[qrcode](https://www.npmjs.com/package/qrcode)** — Small bundle, Node.js and browser compatible

### Encoding Recommendations

- **Size**: Generate at least 200×200 pixels to ensure scanability.
- **Redundancy**: Use high error correction (Level H, or 30% redundancy) so partial damage doesn't break the code.
- **Contrast**: Ensure the QR module (dark squares) has at least a 4.5:1 contrast ratio against the background.
- **Padding**: Leave at least 4 module widths of white space (the "quiet zone") around all edges.

## Minimal Example

A simple receive page with address display, copyable URI, and QR code:

```tsx
'use client';

import { useState } from 'react';
import QRCode from 'qrcode.react';

interface ReceivePageProps {
  publicKey: string;
  memo?: string;
  amount?: string;
}

export function ReceivePage({
  publicKey,
  memo,
  amount,
}: ReceivePageProps) {
  const [copied, setCopied] = useState(false);

  // Build the Stellar URI
  const params = new URLSearchParams();
  if (amount) params.append('amount', amount);
  if (memo) params.append('memo', memo);

  const stellarUri = `stellar:${publicKey}${
    params.toString() ? `?${params.toString()}` : ''
  }`;

  // For display: truncate the address
  const displayAddress =
    publicKey.substring(0, 6) + '...' + publicKey.substring(publicKey.length - 6);

  const handleCopy = async () => {
    try {
      await navigator.clipboard.writeText(publicKey);
      setCopied(true);
      setTimeout(() => setCopied(false), 2000);
    } catch (error) {
      console.error('Failed to copy address:', error);
    }
  };

  const handleDownloadQR = () => {
    const qrElement = document.getElementById('qr-code');
    if (qrElement instanceof HTMLCanvasElement) {
      const link = document.createElement('a');
      link.href = qrElement.toDataURL('image/png');
      link.download = `stellar-receive-${publicKey.substring(0, 10)}.png`;
      link.click();
    }
  };

  return (
    <div className="max-w-md mx-auto p-6 space-y-6">
      <div className="text-center">
        <h1 className="text-2xl font-bold">Receive Stellar Lumens</h1>
        <p className="text-sm text-muted-foreground mt-2">
          Share your address or QR code to receive payments
        </p>
      </div>

      {/* Address Display */}
      <div className="border rounded-lg p-4">
        <p className="text-xs text-muted-foreground mb-2">Your Address</p>
        <p className="font-mono text-sm break-all">{publicKey}</p>
        <button
          onClick={handleCopy}
          className="mt-3 px-3 py-1 bg-primary text-primary-foreground text-sm rounded hover:bg-primary/90"
        >
          {copied ? 'Copied!' : 'Copy Address'}
        </button>
      </div>

      {/* QR Code */}
      <div className="border rounded-lg p-6 flex justify-center bg-white">
        <QRCode
          id="qr-code"
          value={stellarUri}
          size={256}
          level="H"
          includeMargin={true}
          fgColor="#000000"
          bgColor="#ffffff"
        />
      </div>

      {/* Download QR */}
      <button
        onClick={handleDownloadQR}
        className="w-full px-4 py-2 border rounded hover:bg-muted"
      >
        Download QR Code
      </button>

      {/* Info */}
      {(amount || memo) && (
        <div className="bg-muted p-3 rounded text-sm space-y-1">
          {amount && <p>Expected amount: {amount} XLM</p>}
          {memo && <p>Memo: {memo}</p>}
        </div>
      )}
    </div>
  );
}
```

### Usage

```tsx
<ReceivePage
  publicKey="GBBD47UZT552PLLY7TSVVSQYUVJQJLAN47DDIUGACVM87DCAGYIPTU5"
  memo="invoice-123"
  amount="50"
/>
```

### Accessibility

- The QR code is decorative; ensure the address is always readable in text form.
- Use `aria-label` on the QR code canvas: `<QRCode aria-label="Stellar payment QR code" ... />`
- The copy button should announce success to screen readers using `aria-live="polite"`.
- Ensure sufficient color contrast: standard QR codes (black on white) meet WCAG AA at all sizes.

---

## Verification Checklist

- The QR code encodes a valid Stellar URI that resolves to the correct address.
- The address is always displayed alongside the QR code in plain text.
- The copy-to-clipboard button works and announces success.
- The QR code includes at least 4 modules of white padding (quiet zone).
- Optional parameters (amount, memo) are correctly URL-encoded.
- The page works on mobile devices and displays the QR code at a scannable size.
- Color contrast between the QR code and background meets accessibility standards.
