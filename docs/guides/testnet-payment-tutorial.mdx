# End-to-End Testnet Payment Tutorial

Sending payments on the Stellar network is fast, deterministic, and takes 3 to 5 seconds to achieve finality. Nextellar provides the `useStellarPayment` hook to abstract away account sequence number fetching, base fee calculations, transaction envelope building, and network submission.

This tutorial guides you through creating a complete, end-to-end Stellar testnet payment workflow in a Nextellar application.

---

## What We Are Building

By the end of this tutorial, you will have a working payment page that:

1. **Connects a Testnet Wallet** using `useStellarWallet`.
2. **Validates Recipient Addresses and Amounts** using Zod.
3. **Builds and Submits a Native XLM Payment** using `useStellarPayment`.
4. **Tracks Transaction Lifecycle States** (Idle, Submitting, Success, Error).
5. **Displays a Direct Link to the Confirmed Transaction** on Stellar Expert.

---

## 1. Prerequisites & Testnet Account Setup

Before starting, prepare two Stellar Testnet accounts: a **sender** and a **recipient**.

1. **Install Freighter Wallet**: Install the [Freighter browser extension](https://www.freighter.app/) and switch the network to **Testnet** in Settings.
2. **Fund Your Sender Wallet**: Copy your Freighter public key (`G...`) and request 10,000 testnet lumens via [Stellar Friendbot](https://laboratory.stellar.org/#account-creator).
3. **Get a Recipient Key**: Generate a second test account on Stellar Laboratory or use any valid testnet public address.

## 3. Understanding the `useStellarPayment` Hook

The `useStellarPayment` hook provides two workflows for executing payments:

1. **Direct One-Click Execution (`submitPayment`)**: Builds the transaction XDR, delegates signing to the connected wallet, and submits the envelope to the Stellar Horizon endpoint.
2. **Low-Level Transaction Construction (`buildPaymentXDR`)**: Generates the raw base64 transaction XDR for custom multi-sig workflows or manual pre-flight inspection.

### Return Interface

```typescript
export interface UseStellarPaymentReturn {
  isSubmitting: boolean;
  error: Error | null;
  txHash: string | null;
  submitPayment: (params: PaymentParams) => Promise<PaymentResult>;
  buildPaymentXDR: (params: PaymentParams) => Promise<string>;
  reset: () => void;
}

export interface PaymentParams {
  destination: string; // Valid G... address
  amount: string; // Decimal string e.g. "10.5"
  assetCode?: string; // Optional (defaults to native XLM)
  assetIssuer?: string; // Required if assetCode is not native
  memo?: string; // Optional text memo (max 28 bytes)
}
```

## 4. Step-by-Step Payment Form Implementation

Create the component `src/components/TestnetPaymentForm.tsx`:

```tsx
// src/components/TestnetPaymentForm.tsx
'use client';

import React, { useState } from 'react';
import { useStellarWallet } from '@/hooks/useStellarWallet';
import { useStellarPayment } from '@/hooks/useStellarPayment';
import { StrKey } from '@stellar/stellar-sdk';

export function TestnetPaymentForm() {
  const { publicKey, isConnected, connect } = useStellarWallet();
  const { submitPayment, isSubmitting, error, txHash, reset } =
    useStellarPayment();

  const [destination, setDestination] = useState('');
  const [amount, setAmount] = useState('');
  const [memo, setMemo] = useState('');
  const [validationError, setValidationError] = useState<string | null>(null);

  const handleSendPayment = async (e: React.FormEvent) => {
    e.preventDefault();
    setValidationError(null);

    // 1. Validate destination address
    if (!StrKey.isValidEd25519PublicKey(destination)) {
      setValidationError(
        'Invalid destination public key. Must start with "G" and be 56 characters.'
      );
      return;
    }

    // 2. Validate amount
    const numAmount = parseFloat(amount);
    if (isNaN(numAmount) || numAmount <= 0) {
      setValidationError('Amount must be greater than 0.');
      return;
    }

    // 3. Submit transaction using the payment hook
    try {
      await submitPayment({
        destination,
        amount,
        memo: memo.trim() || undefined,
      });
    } catch (err) {
      // Error is also captured in the hook's `error` state
      console.error('Payment failed:', err);
    }
  };

  if (!isConnected) {
    return (
      <div className="p-6 border rounded-xl text-center space-y-4">
        <h3 className="text-lg font-semibold">Connect Your Testnet Wallet</h3>
        <p className="text-muted-foreground text-sm">
          Connect Freighter to send testnet payments.
        </p>
        <button
          onClick={() => connect('freighter')}
          className="px-4 py-2 bg-blue-600 text-white rounded-lg hover:bg-blue-700 transition"
        >
          Connect Freighter
        </button>
      </div>
    );
  }

  return (
    <div className="max-w-md mx-auto p-6 border rounded-xl shadow-sm bg-card space-y-6">
      <div>
        <h2 className="text-xl font-bold">Send Testnet Payment</h2>
        <p className="text-xs text-muted-foreground mt-1 truncate">
          From: <span className="font-mono">{publicKey}</span>
        </p>
      </div>

      {txHash ? (
        <div className="p-4 bg-green-50 border border-green-200 rounded-lg text-green-900 space-y-3">
          <p className="font-semibold text-sm">Payment Confirmed!</p>
          <p className="text-xs font-mono break-all">Hash: {txHash}</p>
          <div className="flex gap-2">
            <a
              href={`https://stellar.expert/explorer/testnet/tx/${txHash}`}
              target="_blank"
              rel="noopener noreferrer"
              className="text-xs text-blue-600 underline font-medium"
            >
              View on Stellar Expert ↗
            </a>
            <button
              onClick={() => {
                reset();
                setAmount('');
                setDestination('');
                setMemo('');
              }}
              className="text-xs text-gray-600 underline ml-auto"
            >
              Send Another Payment
            </button>
          </div>
        </div>
      ) : (
        <form onSubmit={handleSendPayment} className="space-y-4">
          <div>
            <label className="block text-sm font-medium mb-1">
              Recipient Public Address (G...)
            </label>
            <input
              type="text"
              required
              placeholder="GD5..."
              value={destination}
              onChange={(e) => setDestination(e.target.value)}
              className="w-full px-3 py-2 border rounded-md font-mono text-sm"
            />
          </div>

          <div>
            <label className="block text-sm font-medium mb-1">
              Amount (XLM)
            </label>
            <input
              type="number"
              step="any"
              required
              placeholder="10.5"
              value={amount}
              onChange={(e) => setAmount(e.target.value)}
              className="w-full px-3 py-2 border rounded-md text-sm"
            />
          </div>

          <div>
            <label className="block text-sm font-medium mb-1">
              Memo (Optional, max 28 characters)
            </label>
            <input
              type="text"
              maxLength={28}
              placeholder="Invoice #123"
              value={memo}
              onChange={(e) => setMemo(e.target.value)}
              className="w-full px-3 py-2 border rounded-md text-sm"
            />
          </div>

          {validationError && (
            <p className="text-sm text-red-600">{validationError}</p>
          )}

          {error && (
            <p className="text-sm text-red-600 break-words">
              Transaction Error: {error.message}
            </p>
          )}

          <button
            type="submit"
            disabled={isSubmitting}
            className="w-full py-2.5 px-4 bg-primary text-primary-foreground font-semibold rounded-md hover:opacity-90 disabled:opacity-50 transition"
          >
            {isSubmitting ? 'Signing and Submitting...' : 'Send Payment'}
          </button>
        </form>
      )}
    </div>
  );
}
```

## 6. End-to-End Execution Flow

When the user submits the form, the following sequential operations occur:

```text
[ User clicks Send ]
        │
        ▼
[ Form validates public address and amount ]
        │
        ▼
[ useStellarPayment fetches fresh sequence number from Horizon ]
        │
        ▼
[ TransactionBuilder builds XDR envelope with testnet passphrase ]
        │
        ▼
[ Freighter popup requests signature from user ]
        │
        ▼
[ User approves signature in Freighter ]
        │
        ▼
[ Signed envelope submitted to Horizon POST /transactions ]
        │
        ▼
[ Ledger confirms transaction in 3-5 seconds ]
        │
        ▼
[ txHash returned and verified on Stellar Expert ]
```

## 7. Common Testnet Errors & Solutions

| Error Message           | Root Cause                                                            | Solution                                                                                                              |
| ----------------------- | --------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| `op_underfunded`        | Sender account does not have sufficient XLM to cover amount + reserve | Fund sender account via Friendbot.                                                                                    |
| `op_no_destination`     | Destination account is not funded on testnet                          | If sending to an unfunded account, use `createAccount` instead of `payment`, or fund destination with at least 1 XLM. |
| `tx_bad_seq`            | Account sequence number changed since envelope was built              | Re-fetch the account sequence and retry the transaction.                                                              |
| `User rejected request` | The user clicked "Cancel" inside Freighter                            | Handle cancellation gracefully in UI without breaking app state.                                                      |

## 8. Verifying on Stellar Expert

Once the transaction is submitted, click the **View on Stellar Expert** link:

`https://stellar.expert/explorer/testnet/tx/<TX_HASH>`

Verify that:

- The transaction status shows **Successful**.
- The operation type is **Payment**.
- The amount transferred and recipient match your inputs.
- The memo matches the text you supplied.
