# Tabs Component Documentation

The **Tabs** component is a customizable tab system that supports multiple sizes and provides a smooth transition effect. It is designed for modern, theme-aware applications that use CSS variables (defined in your global CSS) for light and dark modes.

## Synced Tabs

Control multiple `Tabs` instances with the same value to keep their selections synchronized. Selecting a tab in either group updates both groups.

<Tabs defaultValue="preview" className="w-full">
  <TabsList className="grid w-full grid-cols-2 md:w-[30%]">
    <Tab value="preview">Preview</Tab>
    <Tab value="code">Code</Tab>
  </TabsList>
  <TabsContent value="preview">
    <Preview>
      {(() => {
        const SyncedTabsExample = () => {
          const [activeTab, setActiveTab] = React.useState('overview');

          return (
            <div className="space-y-8">
              <Tabs
                defaultValue="overview"
                value={activeTab}
                onValueChange={setActiveTab}
              >
                <TabsList>
                  <Tab value="overview">Overview</Tab>
                  <Tab value="activity">Activity</Tab>
                </TabsList>
                <TabsContent value="overview">
                  The account overview is selected.
                </TabsContent>
                <TabsContent value="activity">
                  The account activity is selected.
                </TabsContent>
              </Tabs>

              <Tabs
                defaultValue="overview"
                value={activeTab}
                onValueChange={setActiveTab}
              >
                <TabsList>
                  <Tab value="overview">Overview</Tab>

                </TabsList>

                  This second tab group follows the overview selection.
                </TabsContent>

                  This second tab group follows the activity selection.

import { useState } from 'react';

        <TabsList>
          <Tab value="overview">Overview</Tab>

        </TabsList>

## Props

| Prop            | Type                                   | Default     | Description                                       |
| --------------- | -------------------------------------- | ----------- | ------------------------------------------------- |
| `defaultValue`  | `string`                               | `""`        | The initial active tab when the component mounts. |
| `value`         | `string`                               | `""`        | The controlled value of the active tab.           |
| `onValueChange` | `(value: string) => void`              | `undefined` | Callback function when the active tab changes.    |
| `onTabClick`    | `(value: string) => void`              | `undefined` | Callback function when a tab is clicked.          |
| `size`          | `"xs" \| "sm" \| "md" \| "lg" \| "xl"` | `"md"`      | Controls the size of the tab buttons.             |
| `...props`      | `React.HTMLAttributes<HTMLDivElement>` |             | Supports all standard `div` attributes.           |
