# Payment Application Example

Learn how to build a complete payment application on Stellar using Nextellar. This example covers wallet connection, balance display, sending payments, and transaction history.

**Tested with:** Nextellar CLI 1.0.4, Node.js 20.18.0

## What We'll Build

A full-featured payment app with:

- Multi-wallet connection (Freighter, Albedo, Lobstr, xBull, Hana)
- Real-time balance display
- Send XLM and custom assets
- Transaction history with pagination
- QR code generation for receiving
- Transaction status tracking
- Error handling and validation

## Prerequisites

- Node.js 20.18.0 or later
- A Stellar wallet (Freighter recommended)
- Testnet XLM (get from [Friendbot](https://laboratory.stellar.org/#account-creator))

## Step 1: Create the Project

```bash
npx nextellar stellar-payment-app --template default
cd stellar-payment-app
npm run dev
```

The default template includes all the hooks and components you need. Open [http://localhost:3000](http://localhost:3000) to see the starter app.

## Step 3: Build the Payment Interface

Replace the default `src/app/page.tsx` with:

```tsx
'use client';

import { useState } from 'react';
import { useStellarWallet } from '@/hooks/useStellarWallet';
import WalletConnectButton from '@/components/WalletConnectButton';

export default function PaymentApp() {
  const { connected, publicKey, balances, sendPayment } = useStellarWallet();
  const [recipient, setRecipient] = useState('');
  const [amount, setAmount] = useState('');
  const [memo, setMemo] = useState('');
  const [loading, setLoading] = useState(false);
  const [txHash, setTxHash] = useState('');
  const [error, setError] = useState('');

  const handleSubmit = async (e: React.FormEvent) => {
    e.preventDefault();
    if (!sendPayment) return;

    setLoading(true);
    setError('');
    setTxHash('');

    try {
      const result = await sendPayment({
        to: recipient,
        amount: amount,
        asset: 'XLM',
        memo: memo || undefined,
      });

      setTxHash(result.hash);
      setRecipient('');
      setAmount('');
      setMemo('');
    } catch (err) {
      setError((err as Error).message);
    } finally {
      setLoading(false);
    }
  };

  const xlmBalance =
    balances.find((b) => b.asset_type === 'native')?.balance || '0';

  return (
    <div className="min-h-screen p-8 bg-background">
      <div className="max-w-2xl mx-auto">
        <h1 className="text-4xl font-bold mb-8">Stellar Payment App</h1>

        {/* Wallet Connection */}
        <div className="mb-8">
          <WalletConnectButton />
        </div>

        {connected && (
          <>
            {/* Account Info */}
            <div className="bg-card border rounded-lg p-6 mb-8">
              <h2 className="text-xl font-semibold mb-4">Account Info</h2>
              <div className="space-y-2">
                <div>
                  <span className="text-sm text-muted-foreground">
                    Public Key:
                  </span>
                  <p className="font-mono text-sm break-all">{publicKey}</p>
                </div>
                <div>
                  <span className="text-sm text-muted-foreground">
                    Balance:
                  </span>
                  <p className="text-2xl font-bold">{xlmBalance} XLM</p>
                </div>
              </div>
            </div>

            {/* Payment Form */}
            <div className="bg-card border rounded-lg p-6">
              <h2 className="text-xl font-semibold mb-4">Send Payment</h2>
              <form onSubmit={handleSubmit} className="space-y-4">
                {/* Recipient */}
                <div>
                  <label className="block text-sm font-medium mb-2">
                    Recipient Address
                  </label>
                  <input
                    type="text"
                    value={recipient}
                    onChange={(e) => setRecipient(e.target.value)}
                    placeholder="GDEF456..."
                    className="w-full px-3 py-2 border rounded-md"
                    required
                  />
                </div>

                {/* Amount */}
                <div>
                  <label className="block text-sm font-medium mb-2">
                    Amount (XLM)
                  </label>
                  <input
                    type="number"
                    step="0.0000001"
                    value={amount}
                    onChange={(e) => setAmount(e.target.value)}
                    placeholder="10.5"
                    className="w-full px-3 py-2 border rounded-md"
                    required
                  />
                </div>

                {/* Memo */}
                <div>
                  <label className="block text-sm font-medium mb-2">
                    Memo (optional)
                  </label>
                  <input
                    type="text"
                    value={memo}
                    onChange={(e) => setMemo(e.target.value)}
                    placeholder="Payment note"
                    maxLength={28}
                    className="w-full px-3 py-2 border rounded-md"
                  />
                  <p className="text-xs text-muted-foreground mt-1">
                    Max 28 characters
                  </p>
                </div>

                {/* Submit Button */}
                <button
                  type="submit"
                  disabled={loading}
                  className="w-full px-4 py-2 bg-primary text-primary-foreground rounded-md font-medium hover:opacity-90 disabled:opacity-50"
                >
                  {loading ? 'Sending...' : 'Send Payment'}
                </button>
              </form>

              {/* Success Message */}
              {txHash && (
                <div className="mt-4 p-4 bg-green-50 dark:bg-green-900/20 border border-green-200 dark:border-green-800 rounded-md">
                  <p className="text-sm font-medium text-green-800 dark:text-green-200 mb-1">
                    Payment Successful!
                  </p>
                  <a
                    href={`https://stellar.expert/explorer/testnet/tx/${txHash}`}
                    target="_blank"
                    rel="noopener noreferrer"
                    className="text-sm text-green-600 dark:text-green-400 hover:underline break-all"
                  >
                    View on Stellar Expert ↗
                  </a>
                </div>
              )}

              {/* Error Message */}
              {error && (
                <div className="mt-4 p-4 bg-red-50 dark:bg-red-900/20 border border-red-200 dark:border-red-800 rounded-md">
                  <p className="text-sm text-red-800 dark:text-red-200">
                    {error}
                  </p>
                </div>
              )}
            </div>
          </>
        )}

        {!connected && (
          <div className="bg-muted border rounded-lg p-8 text-center">
            <p className="text-muted-foreground">
              Connect your wallet to send payments
            </p>
          </div>
        )}
      </div>
    </div>
  );
}
```


The hook handles:

- Building the transaction

Balances are automatically fetched and updated when the wallet connects.

## Error Handling

This section covers common failure paths and how to handle them gracefully in your payment application.

### Common Error Types

| Error Category           | Typical Cause                                      | User Action                                  |
| ------------------------ | -------------------------------------------------- | -------------------------------------------- |
| **Wallet Not Connected** | User hasn't connected wallet or connection dropped | Prompt to connect wallet                     |
| **Insufficient Balance** | Not enough XLM for payment + fees                  | Show balance, suggest funding from Friendbot |
| **Invalid Recipient**    | Malformed address or wrong network                 | Validate address format (G..., 56 chars)     |
| **Transaction Rejected** | User declined in wallet                            | Inform user, allow retry                     |
| **Network Error**        | Horizon/RPC unavailable                            | Retry with backoff, show status              |
| **Trustline Missing**    | Sending custom asset without trustline             | Guide to establish trustline first           |

### Error Handling in Code

The `sendPayment` hook throws errors that you can catch and categorize:

```tsx
import { useStellarWallet } from '@/hooks/useStellarWallet';

function PaymentForm() {
  const { sendPayment, balances } = useStellarWallet();
  const [error, setError] = useState<Error | null>(null);

  const handleSend = async (params: PaymentParams) => {
    setError(null);
    try {
      await sendPayment(params);
    } catch (err) {
      const categorized = categorizeError(err);
      setError(categorized);
    }
  };

  return (
    <form onSubmit={handleSend}>
      {/* form fields */}
      {error && <ErrorDisplay error={error} />}
    </form>
  );
}

function categorizeError(err: unknown): AppError {
  const message = err instanceof Error ? err.message : String(err);

  // Wallet connection errors
  if (message.includes('wallet') || message.includes('connect')) {
    return {
      type: 'wallet',
      message: 'Wallet not connected. Please connect your wallet first.',
    };
  }

  // Insufficient balance
  if (message.includes('insufficient') || message.includes('balance')) {
    return {
      type: 'balance',
      message:
        'Insufficient XLM balance. You need at least 1 XLM reserve + fee.',
    };
  }

  // Invalid address
  if (message.includes('invalid') || message.includes('address')) {
    return {
      type: 'address',
      message:
        'Invalid recipient address. Must be a valid Stellar public key (G..., 56 characters).',
    };
  }

  // User rejected
  if (
    message.includes('reject') ||
    message.includes('cancel') ||
    message.includes('denied')
  ) {
    return {
      type: 'rejected',
      message:
        'Transaction was rejected. Please approve the transaction in your wallet.',
    };
  }

  // Network issues
  if (
    message.includes('network') ||
    message.includes('timeout') ||
    message.includes('fetch')
  ) {
    return {
      type: 'network',
      message: 'Network error. Please check your connection and try again.',
    };
  }

  // Trustline missing
  if (message.includes('trustline') || message.includes('change trust')) {
    return {
      type: 'trustline',
      message:
        'Missing trustline for this asset. Please establish a trustline first.',
    };
  }

  return {
    type: 'unknown',
    message: 'An unexpected error occurred. Please try again.',
  };
}

interface AppError {
  type:
    | 'wallet'
    | 'balance'
    | 'address'
    | 'rejected'
    | 'network'
    | 'trustline'
    | 'unknown';
  message: string;
}

function ErrorDisplay({ error }: { error: AppError }) {
  const recoveryActions: Record<AppError['type'], React.ReactNode> = {
    wallet: <WalletConnectButton />,
    balance: (
      <a
        href="https://laboratory.stellar.org/#account-creator"
        target="_blank"
        rel="noopener noreferrer"
      >
        Get Testnet XLM ↗
      </a>
    ),
    address: <p>Double-check the recipient address format.</p>,
    rejected: <button onClick={() => setError(null)}>Try Again</button>,
    network: <button onClick={() => handleSend(params)}>Retry</button>,
    trustline: (
      <a
        href="/docs/hooks/use-trustlines"
        target="_blank"
        rel="noopener noreferrer"
      >
        Learn about trustlines ↗
      </a>
    ),
    unknown: <button onClick={() => handleSend(params)}>Retry</button>,
  };

  return (
    <div
      className="p-4 bg-red-50 dark:bg-red-900/20 border border-red-200 dark:border-red-800 rounded-md"
      role="alert"
    >
      <p className="text-sm font-medium text-red-800 dark:text-red-200 mb-2">
        {error.message}
      </p>
      <div className="text-sm text-red-700 dark:text-red-300">
        {recoveryActions[error.type]}
      </div>
    </div>
  );
}
```

### Validation Best Practices

#### Client-Side Validation

Validate before submitting to avoid unnecessary wallet prompts:

```tsx
function validatePayment(params: PaymentParams): string | null {
  // Check wallet connected
  if (!connected) return 'Please connect your wallet first';

  // Validate recipient
  if (!params.to || !/^G[A-Z0-9]{55}$/.test(params.to)) {
    return 'Invalid recipient address';
  }

  // Validate amount
  const amount = parseFloat(params.amount);
  if (isNaN(amount) || amount <= 0) {
    return 'Amount must be greater than 0';
  }

  // Check sufficient balance (including fee)
  const required = amount + 0.00001; // base fee
  const available = parseFloat(xlmBalance);
  if (available < required) {
    return `Insufficient balance. Need ${required} XLM, have ${available} XLM`;
  }

  // Memo length
  if (params.memo && params.memo.length > 28) {
    return 'Memo exceeds 28 characters';
  }

  return null;
}
```

#### Server-Side Validation (API Routes)

If you build an API layer, validate again server-side:

```tsx

export async function POST(request: Request) {

}
```

### Error Recovery Strategies

#### 1. Automatic Retry with Exponential Backoff

```tsx
async function sendWithRetry(
  params: PaymentParams,
  maxRetries = 3
): Promise<TxResult> {
  for (let attempt = 1; attempt <= maxRetries; attempt++) {
    try {
      return await sendPayment(params);
    } catch (err) {
      const categorized = categorizeError(err);

      // Don't retry user rejections or validation errors
      if (['rejected', 'address', 'balance'].includes(categorized.type)) {
        throw err;
      }

      if (attempt === maxRetries) throw err;

      // Exponential backoff: 1s, 2s, 4s
      await new Promise((r) => setTimeout(r, 1000 * Math.pow(2, attempt - 1)));
    }
  }
}
```

#### 2. Optimistic UI with Rollback

```tsx
const [pendingTx, setPendingTx] = useState<PaymentParams | null>(null);

const handleSend = async (params: PaymentParams) => {
  setPendingTx(params); // Show pending state immediately
  try {
    const result = await sendPayment(params);
    setPendingTx(null);
    setTxHash(result.hash);
  } catch (err) {
    setPendingTx(null); // Rollback
    setError(categorizeError(err));
  }
};

// In render:
{
  pendingTx && (
    <div className="bg-yellow-50 border-yellow-200 p-4 rounded">
      <p>Processing payment of {pendingTx.amount} XLM...</p>
    </div>
  );
}
```

#### 3. Offline Queue

Queue payments when offline, send when reconnected:

```tsx
const [offlineQueue, setOfflineQueue] = useState<PaymentParams[]>([]);

const handleSend = async (params: PaymentParams) => {
  if (!navigator.onLine) {
    setOfflineQueue((prev) => [...prev, params]);
    setError({
      type: 'network',
      message: 'Offline. Payment queued for when connection returns.',
    });
    return;
  }
  // ... normal send logic
};

// Process queue when online
useEffect(() => {
  const handleOnline = async () => {
    for (const params of offlineQueue) {
      try {
        await sendPayment(params);
      } catch {
        /* keep in queue */
      }
    }
    setOfflineQueue([]);
  };

  window.addEventListener('online', handleOnline);
  return () => window.removeEventListener('online', handleOnline);
}, [offlineQueue]);
```

## Troubleshooting

### Wallet Connection Fails

- Ensure Freighter wallet is installed and unlocked
- Check that you're on the correct network (testnet)
- Try refreshing the page

### Payment Fails

- Verify recipient address is valid (starts with 'G', 56 characters)
- Ensure you have sufficient XLM balance (minimum 1 XLM reserve)
- Check that amount is greater than 0

### Transactions Not Appearing

- Wait a few seconds for network confirmation (5-10 seconds typical)
- Check [Stellar Expert](https://stellar.expert/explorer/testnet) for transaction status
- Verify you're on the correct network (testnet vs mainnet)
