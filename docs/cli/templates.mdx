# Nextellar CLI Scaffolding Templates

Nextellar has three template families, each available in TypeScript and JavaScript. The CLI's `TEMPLATE_LIST` contains the three selectable family names: `default`, `minimal`, and `defi`. Add `--javascript` to choose the corresponding JavaScript source directory.

```bash
npx nextellar my-app --template default
npx nextellar my-js-app --template default --javascript
```

Omitting `--template` selects `default`; TypeScript is the default language. The JavaScript directory names (`js-template`, `js-minimal`, and `js-defi`) are internal scaffold IDs, not valid values for `--template`.

```bash
npx nextellar my-app --template minimal --javascript
npx nextellar my-app --template defi --javascript
```

> **Not sure which template to choose?** See the [Template Comparison](/docs/cli/template-comparison) for a feature-by-feature breakdown.

## Six scaffold variants

| Variant | Internal directory | Command | What it is for |
| --- | --- | --- | --- |
| `default` (TypeScript) | `default` | `nextellar my-app --template default` | Full Stellar starter with wallet and balances, payments, transaction history, trustlines, offer-book access, Soroban contract/event hooks, and network switching. |
| `default` (JavaScript) | `js-template` | `nextellar my-app --template default --javascript` | The full starter in `.js`/`.jsx`, with the same broad wallet, payment, history, and Soroban use cases. |
| `minimal` (TypeScript) | `minimal` | `nextellar my-app --template minimal` | A small starting point centered on wallet connection and balances, for apps that will add their own UI and features. |
| `minimal` (JavaScript) | `js-minimal` | `nextellar my-app --template minimal --javascript` | The minimal starter in `.js`/`.jsx`, without TypeScript configuration or source files. |
| `defi` (TypeScript) | `defi` | `nextellar my-app --template defi` | A DeFi-oriented starter for swap, liquidity-pool, and price-feed experiences. |
| `defi` (JavaScript) | `js-defi` | `nextellar my-app --template defi --javascript` | The DeFi starter in `.js`/`.jsx` for teams not using TypeScript. |

The `--template` flag accepts only the three family names in `TEMPLATE_LIST`: `default`, `minimal`, and `defi`. The JavaScript variants are selected by combining one of those values with `--javascript` (or `-j`); passing an internal directory name such as `js-minimal` directly to `--template` is not supported.

## TypeScript and JavaScript

TypeScript is selected by default and generates `.ts`/`.tsx` files with TypeScript configuration. Add `--javascript` or `-j` to generate `.js`/`.jsx` files and JavaScript configuration instead. The language option does not change the template family you select.

```bash
npx nextellar my-app --template minimal
npx nextellar my-js-app --template minimal --javascript
```

See [Using JavaScript](/docs/getting-started/javascript) for language details and [Create a JavaScript project](/docs/cli/js-template) for the default JavaScript starter.

## Add Soroban contracts

`--with-contracts` adds a Soroban `hello_world` contract (Rust, under `contracts/`) to the selected template. It also adds `contracts:build` and `contracts:test` scripts and a `NEXT_PUBLIC_HELLO_WORLD_CONTRACT_ID` entry to `.env.example`.

```bash
npx nextellar my-app --template defi --with-contracts
```

See the [Contracts Quick Start](/docs/getting-started/contracts-quick-start) for building and invoking the generated contract.
