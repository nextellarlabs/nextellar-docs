# Template Comparison

Nextellar provides three template families, each with TypeScript and JavaScript source variants. Select a family with `--template`; add `--javascript` (or `-j`) for its JavaScript variant. Internal directory names such as `js-template` are not `--template` values.

## Quick Template Guide

| Template family | TypeScript directory | JavaScript directory | Best for                                                                             |
| --------------- | -------------------- | -------------------- | ------------------------------------------------------------------------------------ |
| `default`       | `default`            | `js-template`        | Full Stellar apps that need the broad wallet, transaction, and Soroban hook set.     |
| `minimal`       | `minimal`            | `js-minimal`         | Lightweight wallet applications and incremental feature development.                 |
| `defi`          | `defi`               | `js-defi`            | DeFi interfaces using the starter's swap, liquidity-pool, and price-feed components. |

## Template Details

### default

The full starter includes wallet connection, balances, transaction history, a network switcher, and the broadest set of classic Stellar and Soroban hooks.

- **Wallet Features**: Connection, balance display, payment sending
- **Soroban Integration**: Smart contract calls and event listening
- **Transaction Tools**: Full transaction history and network switching
- **DeFi Capabilities**: Asset trustlines and DEX order book access
- **Configuration**: Network switching, persistent storage, environment setup

**Choose default when**: Building a full-featured Stellar application that needs broad functionality out of the box.

### minimal

The lightweight family centers on wallet connection and balances. Its TypeScript source also includes transaction history; the JavaScript variant is smaller and omits that hook.

**Choose minimal when**: Building a wallet-focused application or adding features incrementally.

### defi

The DeFi family includes wallet and payment hooks, trustlines, offer-book access, and a DeFi-oriented starter UI. The TypeScript variant also includes Soroban contract and event hooks; the JavaScript variant does not.

**Choose defi when**: Building a DeFi interface using the starter's swap, liquidity-pool, or price-feed components.

## JavaScript Support

The `--javascript` flag generates `.jsx`/`.js` files instead of TypeScript. All three template families have JavaScript source directories:

```bash
npx nextellar my-app --javascript
npx nextellar my-app --javascript --template defi
```

The CLI's `TEMPLATE_LIST` accepts only `default`, `minimal`, and `defi`; the internal JavaScript directory names are not accepted as `--template` values.

## Smart Contract Support

The `--with-contracts` flag adds Soroban smart contract scaffolding to any template:

```bash
npx nextellar my-app --template defi --with-contracts
```

**What `--with-contracts` adds:**

- Sample `hello_world` contract in Rust under `contracts/`
- `contracts:build` and `contracts:test` npm scripts
- `NEXT_PUBLIC_HELLO_WORLD_CONTRACT_ID` in `.env.example`

**Note**: `--with-contracts` is an orthogonal overlay that adds contract tooling to your chosen template, not a separate template category.

## Choosing the Right Template

### Start with default if:

- You're new to Stellar development
- You want to explore all available features
- You're building a comprehensive dApp
- You need transaction history or network switching

### Choose minimal if:

- You only need wallet connection and balances
- You're building a simple wallet interface
- You prefer to add features incrementally
- You want the smallest possible starting point

### Pick defi if:

- You're building DEX or trading interfaces
- You need trustline and order book features
- You're focusing on DeFi use cases
- You want DeFi starter components; the TypeScript variant also includes Soroban contract and event hooks

## Template Migration

You can add features from other templates to your existing project using the CLI's `add` command:

```bash
## Add features to an existing project
nextellar add soroban-contract
nextellar add transaction-history
```

See [Extending the CLI](/docs/guides/extending-the-cli) for the complete feature catalog.
