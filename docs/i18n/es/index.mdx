# Bienvenido a la Documentación de Nextellar

**Nextellar** es un toolkit CLI de un solo paso que proporciona aplicaciones Next.js + TypeScript listas para producción con soporte integrado para blockchain Stellar. Ve de la idea a una dApp funcional en menos de 2 minutos.

## Inicio Rápido

```bash
npx nextellar mi-app-stellar
cd mi-app-stellar
npm run dev
```

¡Eso es todo! Ahora tienes una dApp Stellar completamente funcional con conexión de billeteras, hooks de pago e integración de contratos inteligentes.

## ¿Por Qué Nextellar?

### Experiencia del Desarrollador Primero

Nextellar elimina semanas de configuración de boilerplate. En lugar de configurar SDK de Stellar, adaptadores de billeteras, constructores de transacciones y manejo de errores desde cero, obtienes:

- **Configuración Instantánea**: Un comando para estructurar una dApp completa.
- **Seguridad de Tipos**: Soporte completo de TypeScript con definiciones de tipos exhaustivas.
- **Mejores Prácticas**: Arquitectura opinada siguiendo estándares de la industria.
- **Cero Configuración**: Todo funciona lista para usar.

### Código de Calidad Empresarial

Cada hook y componente está listo para producción:

- Manejo exhaustivo de errores.
- Estados de carga y retroalimentación al usuario.
- Persistencia de conexión de billetera.
- Soporte para cambio de red.
- Lógica de reintento de transacciones.
- Mejores prácticas de seguridad.

### Integración Completa de Stellar

- **Horizon API**: Consultas de cuenta, historial de pagos, gestión de activos.
- **Soroban RPC**: Invocación de contratos inteligentes y escucha de eventos.
- **Kit de Billeteras**: Interfaz unificada para todas las billeteras principales de Stellar.
- **Manejo XDR**: Conversión automática entre tipos JavaScript y Stellar.

## Ejemplo: Flujo de Pago

Aquí se ve lo fácil que es enviar un pago con Nextellar:

```tsx
import { useStellarWallet } from '@/hooks/useStellarWallet';

export default function SendPayment() {
  const { connected, sendPayment } = useStellarWallet();

  const handleSend = async () => {
    try {
      const result = await sendPayment({
        to: 'GDEF456...',
        amount: '10.5',
        asset: 'XLM',
        memo: 'Pago por servicios',
      });

      console.log('¡Éxito!', result.hash);
    } catch (error) {
      console.error('El pago falló:', error);
    }
  };

  return (
    <button onClick={handleSend} disabled={!connected}>
      Enviar 10.5 XLM
    </button>
  );
}
```

¡Eso es todo! Sin construir transacciones manuales, sin codificación XDR, sin configuración de adaptador de billetera - simplemente funciona.
