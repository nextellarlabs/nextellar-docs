# Hooks Cookbook

Nextellar provides 12 specialized React hooks for interacting with the Stellar blockchain, Horizon RPC, and Soroban smart contracts. While each hook functions independently, real-world decentralized applications routinely compose multiple hooks together to deliver seamless user experiences.

This cookbook offers production-ready, runnable recipes that demonstrate how to coordinate state, handle dependencies, and manage side effects across multiple Nextellar hooks.

---

## Recipe 1: Authenticated Portfolio Dashboard with Live Asset Valuation

**Hooks Composed:** `useStellarWallet` + `useStellarBalances`

### Use Case

When users connect their wallet, display the native XLM and issued-asset balances loaded from Horizon.

### Implementation

```tsx
'use client';

import { useStellarWallet } from '@/hooks/useStellarWallet';
import { useStellarBalances } from '@/hooks/useStellarBalances';

export function PortfolioDashboard() {
  const { connected, publicKey, connect, disconnect, walletName } =
    useStellarWallet();
  const {
    balances,
    loading: balancesLoading,
    error: balancesError,
    refresh,
  } = useStellarBalances(publicKey);
  const xlmBalance =
    balances.find((balance) => balance.asset_type === 'native')?.balance ?? '0';

  if (!connected || !publicKey) {
    return (
      <div className="p-6 border rounded-lg text-center space-y-4">
        <h3 className="text-lg font-semibold">Connect Your Wallet</h3>
        <p className="text-sm text-muted-foreground">
          Connect your Stellar wallet to view balances and real-time portfolio
          valuation.
        </p>
        <button
          onClick={() => void connect()}
          className="px-4 py-2 bg-primary text-primary-foreground rounded-md text-sm font-medium hover:opacity-90"
        >
          Connect Freighter
        </button>
      </div>
    );
  }

  return (
    <div className="p-6 border rounded-lg space-y-6">
      <div className="flex items-center justify-between">
        <div>
          <span className="text-xs font-mono text-muted-foreground">
            Connected via {walletName}
          </span>
          <p className="text-sm font-mono truncate max-w-xs">{publicKey}</p>
        </div>
        <div className="flex gap-2">
          <button
            onClick={() => void refresh()}
            disabled={balancesLoading}
            className="px-3 py-1.5 border rounded-md text-xs font-medium hover:bg-accent"
          >
            {balancesLoading ? 'Refreshing...' : 'Refresh'}
          </button>
          <button
            onClick={disconnect}
            className="px-3 py-1.5 bg-destructive text-destructive-foreground rounded-md text-xs font-medium"
          >
            Disconnect
          </button>
        </div>
      </div>

      {balancesError && (
        <div className="p-3 bg-red-100 dark:bg-red-900/30 text-red-700 dark:text-red-300 rounded text-sm">
          {balancesError.message}
        </div>
      )}

      <div className="grid grid-cols-1 sm:grid-cols-2 gap-4">
        <div className="p-4 border rounded-md">
          <p className="text-xs text-muted-foreground">Available XLM</p>
          <p className="text-2xl font-bold">
            {Number(xlmBalance).toLocaleString()} XLM
          </p>
        </div>
      </div>

      <div className="space-y-2">
        <h4 className="text-sm font-semibold">Holdings</h4>
        <div className="divide-y border rounded-md overflow-hidden">
          {balances.map((item, idx) => (
            <div
              key={idx}
              className="flex justify-between items-center p-3 text-sm"
            >
              <span className="font-medium">
                {item.asset_type === 'native'
                  ? 'XLM (Native)'
                  : item.asset_code}
              </span>
              <span className="font-mono">
                {parseFloat(item.balance).toFixed(4)}
              </span>
            </div>
          ))}
        </div>
      </div>
    </div>
  );
}
```

## Recipe 2: Validated Payment Dispatcher with Automatic Sequence & History Sync

**Hooks Composed:** `useStellarPayment` + `useTransactionHistory` + `useStellarBalances`

### Use Case

Submitting a payment requires validating inputs, executing the payment, and immediately triggering an optimistic or reactive refresh of both the user's balances and their transaction history ledger without requiring a full page reload.

### Implementation

```tsx
'use client';

import React, { useState } from 'react';
import { useStellarPayment } from '@/hooks/useStellarPayment';
import { useTransactionHistory } from '@/hooks/useTransactionHistory';
import { useStellarBalances } from '@/hooks/useStellarBalances';

interface PaymentFormProps {
  senderPublicKey: string;
  signWithWallet: (unsignedXdr: string) => Promise<string>;
}

export function PaymentDispatcher({
  senderPublicKey,
  signWithWallet,
}: PaymentFormProps) {
  const [recipient, setRecipient] = useState('');
  const [amount, setAmount] = useState('');
  const [memo, setMemo] = useState('');
  const [feedback, setFeedback] = useState<string | null>(null);
  const [submitting, setSubmitting] = useState(false);

  const { buildPaymentXDR, submitSignedXDR } = useStellarPayment();
  const { refresh: refreshBalances } = useStellarBalances(senderPublicKey);
  const {
    items,
    loading: historyLoading,
    refresh: refreshHistory,
  } = useTransactionHistory(senderPublicKey, { pageSize: 5, type: 'payments' });

  const handlePayment = async (e: React.FormEvent) => {
    e.preventDefault();
    setFeedback(null);

    if (!recipient.startsWith('G') || recipient.length !== 56) {
      setFeedback('Invalid Stellar public key format.');
      return;
    }

    if (parseFloat(amount) <= 0 || isNaN(parseFloat(amount))) {
      setFeedback('Amount must be greater than zero.');
      return;
    }

    setSubmitting(true);
    try {
      const unsignedXdr = await buildPaymentXDR({
        from: senderPublicKey,
        to: recipient,
        amount,
        asset: 'XLM',
        memo: memo || undefined,
      });
      const signedXdr = await signWithWallet(unsignedXdr);
      const result = await submitSignedXDR(signedXdr);
      if (!result.success) throw new Error(result.error ?? 'Payment failed');

      setFeedback(
        `Payment submitted: ${result.txHash?.slice(0, 12) ?? 'pending'}...`
      );
      setRecipient('');
      setAmount('');
      setMemo('');

      await Promise.all([refreshBalances(), refreshHistory()]);
    } catch (error) {
      setFeedback(error instanceof Error ? error.message : 'Payment failed.');
    } finally {
      setSubmitting(false);
    }
  };

  return (
    <div className="space-y-6">
      <form
        onSubmit={handlePayment}
        className="p-5 border rounded-lg space-y-4"
      >
        <h3 className="text-base font-semibold">Send Payment</h3>

        <div>
          <label className="text-xs font-medium">Destination Public Key</label>
          <input
            type="text"
            value={recipient}
            onChange={(e) => setRecipient(e.target.value)}
            placeholder="G..."
            className="w-full mt-1 p-2 text-sm font-mono border rounded-md bg-background"
            required
          />
        </div>

        <div className="grid grid-cols-2 gap-4">
          <div>
            <label className="text-xs font-medium">Amount (XLM)</label>
            <input
              type="number"
              step="0.0000001"
              min="0.0000001"
              value={amount}
              onChange={(e) => setAmount(e.target.value)}
              placeholder="10.0"
              className="w-full mt-1 p-2 text-sm border rounded-md bg-background"
              required
            />
          </div>
          <div>
            <label className="text-xs font-medium">Memo (Optional)</label>
            <input
              type="text"
              maxLength={28}
              value={memo}
              onChange={(e) => setMemo(e.target.value)}
              placeholder="Invoice #1024"
              className="w-full mt-1 p-2 text-sm border rounded-md bg-background"
            />
          </div>
        </div>

        {feedback && (
          <div className="p-3 text-xs bg-muted rounded-md font-mono">
            {feedback}
          </div>
        )}

        <button
          type="submit"
          disabled={submitting}
          className="w-full py-2 bg-primary text-primary-foreground rounded-md text-sm font-medium hover:opacity-90 disabled:opacity-50"
        >
          {submitting ? 'Submitting to Stellar...' : 'Confirm & Send Payment'}
        </button>
      </form>

      <div className="p-5 border rounded-lg space-y-3">
        <div className="flex justify-between items-center">
          <h4 className="text-sm font-semibold">Recent Activity</h4>
          {historyLoading && (
            <span className="text-xs text-muted-foreground">Syncing...</span>
          )}
        </div>
        <div className="space-y-2">
          {items.slice(0, 3).map((item) => (
            <div
              key={item.id}
              className="p-2.5 border rounded-md text-xs flex justify-between items-center"
            >
              <span className="font-mono text-muted-foreground">
                {item.id.slice(0, 8)}...
              </span>
              <span className="font-medium">{item.type}</span>
              <span className="text-muted-foreground">
                {new Date(item.created_at).toLocaleTimeString()}
              </span>
            </div>
          ))}
        </div>
      </div>
    </div>
  );
}
```

## Recipe 3: Trustline Guarded DEX Order Book Swapper

**Hooks Composed:** `useTrustlines` + `useOfferBook` + `useStellarWallet`

### Use Case

Before receiving a non-native token, an account needs a trustline. This recipe checks trustline readiness, polls a DEX order book, and passes an unsigned change-trust transaction to a caller-provided wallet flow.

### Implementation

```tsx
'use client';

import React, { useMemo } from 'react';
import { useStellarWallet } from '@/hooks/useStellarWallet';
import { useTrustlines } from '@/hooks/useTrustlines';
import { useOfferBook } from '@/hooks/useOfferBook';

const TARGET_ASSET = {
  code: 'USDC',
  issuer: 'GBBD47IF6LWK7P7MDEVSCWR7DPUWV3NY3DTQEVFL4NAT4AQH3ZLLFLA5',
};

export function DEXSwapper({
  signChangeTrust,
}: {
  signChangeTrust: (xdr: string) => Promise<void>;
}) {
  const { connected, publicKey } = useStellarWallet();
  const {
    trustlines,
    buildChangeTrustXDR,
    loading: trustlineLoading,
  } = useTrustlines(publicKey);

  // Monitor orderbook depth for XLM/USDC
  const {
    bids,
    asks,
    loading: bookLoading,
  } = useOfferBook(TARGET_ASSET, 'XLM', { pollIntervalMs: 5000 });

  // Verify whether active trustline exists
  const hasTrustline = useMemo(() => {
    return trustlines.some(
      (tl) =>
        tl.asset_code === TARGET_ASSET.code &&
        tl.asset_issuer === TARGET_ASSET.issuer
    );
  }, [trustlines]);

  if (!connected) {
    return (
      <p className="text-sm text-muted-foreground">
        Please connect your wallet to view trading pair.
      </p>
    );
  }

  const handleAddTrustline = async () => {
    const unsignedXdr = await buildChangeTrustXDR({
      code: TARGET_ASSET.code,
      issuer: TARGET_ASSET.issuer,
    });
    await signChangeTrust(unsignedXdr);
  };

  return (
    <div className="p-5 border rounded-lg space-y-5">
      <div className="flex justify-between items-center border-b pb-3">
        <h3 className="font-semibold text-base">
          XLM / {TARGET_ASSET.code} Liquidity Pool
        </h3>
        <span className="text-xs px-2 py-0.5 rounded bg-muted font-mono">
          Status: {hasTrustline ? 'Trustline Active' : 'Trustline Required'}
        </span>
      </div>

      {!hasTrustline && (
        <div className="p-4 bg-muted rounded-md space-y-2">
          <p className="text-xs text-muted-foreground">
            You must open a trustline for {TARGET_ASSET.code} before you can
            receive or trade this asset.
          </p>
          <button
            onClick={() => void handleAddTrustline()}
            disabled={trustlineLoading}
            className="px-4 py-2 bg-primary text-primary-foreground text-xs font-medium rounded hover:opacity-90 disabled:opacity-50"
          >
            {trustlineLoading
              ? 'Preparing Trustline...'
              : `Prepare ${TARGET_ASSET.code} Trustline`}
          </button>
        </div>
      )}

      <div className="grid grid-cols-2 gap-4">
        <div className="border rounded-md p-3">
          <h5 className="text-xs font-semibold text-green-600 mb-2">
            Bids (Buy Orders)
          </h5>
          {bookLoading ? (
            <p className="text-xs text-muted-foreground">Loading bids...</p>
          ) : (
            <div className="space-y-1">
              {bids.slice(0, 4).map((bid, i) => (
                <div key={i} className="flex justify-between text-xs font-mono">
                  <span>${parseFloat(bid.price).toFixed(4)}</span>
                  <span className="text-muted-foreground">
                    {parseFloat(bid.amount).toFixed(1)}
                  </span>
                </div>
              ))}
            </div>
          )}
        </div>

        <div className="border rounded-md p-3">
          <h5 className="text-xs font-semibold text-red-600 mb-2">
            Asks (Sell Orders)
          </h5>
          {bookLoading ? (
            <p className="text-xs text-muted-foreground">Loading asks...</p>
          ) : (
            <div className="space-y-1">
              {asks.slice(0, 4).map((ask, i) => (
                <div key={i} className="flex justify-between text-xs font-mono">
                  <span>${parseFloat(ask.price).toFixed(4)}</span>
                  <span className="text-muted-foreground">
                    {parseFloat(ask.amount).toFixed(1)}
                  </span>
                </div>
              ))}
            </div>
          )}
        </div>
      </div>
    </div>
  );
}
```

## Recipe 4: Soroban Smart Contract Interaction with Real-Time Event Stream

**Hooks Composed:** `useSorobanContract` + `useSorobanEvents` + `useStellarBalances`

### Use Case

Preview Soroban contract calls with simulation metadata while polling contract events. The hook does not submit a signed invocation; wallet signing and RPC submission remain an explicit separate step.

### Implementation

```tsx
'use client';

import React, { useState } from 'react';
import { useSorobanContract } from '@/hooks/useSorobanContract';
import { useSorobanEvents } from '@/hooks/useSorobanEvents';
import { useStellarBalances } from '@/hooks/useStellarBalances';

const LIQUIDITY_CONTRACT_ID = 'CBG765...CONTRACT_ID';

export function SorobanLiquidityManager({
  userPublicKey,
}: {
  userPublicKey: string;
}) {
  const [depositAmount, setDepositAmount] = useState('');
  const [txStatus, setTxStatus] = useState<string | null>(null);

  // Contract instance
  const { simulateContractCall, loading: simulating } = useSorobanContract({
    contractId: LIQUIDITY_CONTRACT_ID,
    network: 'TESTNET' as const,
  });

  // Poll contract events; this is not a push subscription.
  const {
    events,
    loading: eventsLoading,
    isRecovering,
  } = useSorobanEvents(LIQUIDITY_CONTRACT_ID, {
    pollIntervalMs: 5000,
    limit: 5,
  });

  const { refresh: refreshBalances } = useStellarBalances(userPublicKey);

  const handlePreview = async () => {
    if (!depositAmount || parseFloat(depositAmount) <= 0) return;

    setTxStatus('Simulating deposit on Soroban...');
    try {
      const preview = await simulateContractCall('deposit', [
        { value: userPublicKey, type: 'address' },
        {
          value: BigInt(Math.floor(parseFloat(depositAmount) * 10_000_000)),
          type: 'u128',
        },
      ]);
      setTxStatus(
        `Simulation result: ${String(preview.result)}; minimum resource fee: ${preview.minResourceFee} stroops`
      );
    } catch (error) {
      setTxStatus(error instanceof Error ? error.message : 'Simulation failed');
    }
  };

  return (
    <div className="p-6 border rounded-lg space-y-6">
      <h3 className="font-semibold text-lg">Soroban Liquidity Pool Deposit</h3>

      <div className="flex gap-3">
        <input
          type="number"
          value={depositAmount}
          onChange={(e) => setDepositAmount(e.target.value)}
          placeholder="Deposit units (e.g. 50)"
          className="flex-1 p-2 border rounded-md text-sm bg-background"
        />
        <button
          onClick={handlePreview}
          disabled={simulating}
          className="px-4 py-2 bg-primary text-primary-foreground rounded-md text-sm font-medium hover:opacity-90 disabled:opacity-50"
        >
          {simulating ? 'Simulating...' : 'Preview deposit'}
        </button>
      </div>

      {txStatus && (
        <p className="text-xs font-mono bg-muted p-3 rounded-md">{txStatus}</p>
      )}

      <div className="space-y-3">
        <h4 className="text-sm font-semibold">Recent Contract Events</h4>
        {isRecovering && (
          <p role="status">RPC unavailable; retrying with backoff.</p>
        )}
        {eventsLoading ? (
          <p className="text-xs text-muted-foreground">
            Listening for contract events...
          </p>
        ) : (
          <div className="space-y-2">
            {events.length === 0 ? (
              <p className="text-xs text-muted-foreground">
                No recent events emitted.
              </p>
            ) : (
              events.map((evt, idx) => (
                <div
                  key={idx}
                  className="p-3 border rounded-md text-xs font-mono flex justify-between items-center"
                >
                  <span>Ledger: {evt.ledger}</span>
                  <span className="text-muted-foreground">
                    Type: {evt.type}
                  </span>
                  <span className="font-semibold text-primary">
                    {evt.topic.join(' > ')}
                  </span>
                </div>
              ))
            )}
          </div>
        )}
      </div>
    </div>
  );
}
```

## Best Practices for Hook Composition

1. **Avoid Duplicate Polling Loops**:
   Do not initiate multiple independent polling timers on the same ledger resource. Centralize refetches in response to transaction finality.
2. **Network Alignment**:
   Always pair transaction execution hooks (`useStellarPayment`, `useSorobanContract`) with `useNetworkGuard` to prevent signing operations intended for Testnet on Mainnet.
3. **Graceful Degraded State**:
   Always handle loading and unauthenticated states gracefully when optional dependencies (such as a connected wallet public key) are null.
