# useSorobanContract

The `useSorobanContract` hook provides a complete interface for interacting with Soroban smart contracts. It handles XDR value conversion, transaction simulation, and contract invocation.

<Note>
  **Ships in:** `default`, `js-template`, and the TypeScript `defi` variant.
  <br />
  Check `nextellar add --list` for features available to add to another
  scaffold.
</Note>

## Features

- **Read-Only Calls**: Simulate contract functions without submitting transactions
- **Build Invocations**: Create unsigned contract invocation XDR
- **Dev-Only Submission**: Sign and submit with secret keys (testing)
- **Automatic XDR Conversion**: JavaScript → Stellar type conversion
- **Complex Types**: Support for maps, vectors, addresses, and custom types

## Basic Usage

```tsx
import { useSorobanContract } from '@/hooks/useSorobanContract';

export default function ContractDemo() {
  const { callFunction, simulateContractCall, loading, error } =
    useSorobanContract({
      contractId: 'CDLZFC3SYJYDZT7K67VZ75HPJVIEUVNIXF47ZG2FB2RMQQAHHXK3AWCM',
      network: 'TESTNET' as const,
    });

  const handleReadContract = async () => {
    const result = await callFunction('balance', [
      { value: 'GABC123...', type: 'address' },
    ]);
    console.log('Balance:', result);
  };

  const handlePreview = async () => {
    const preview = await simulateContractCall('balance', [
      { value: 'GABC123...', type: 'address' },
    ]);
    console.log('Decoded result:', preview.result);
    console.log('Minimum resource fee:', preview.minResourceFee);
  };

  return (
    <div>
      {error && <p role="alert">{error.message}</p>}
      <button onClick={handleReadContract} disabled={loading}>
        Read Contract {loading && '(Loading...)'}
      </button>
      <button onClick={handlePreview} disabled={loading}>
        Preview
      </button>
    </div>
  );
}
```

## API Reference

### Parameters

```typescript
function useSorobanContract(options: {
  contractId: string;
  sorobanRpc?: string;
  network?: 'TESTNET' | 'PUBLIC';
}): SorobanContractReturn;
```

| Parameter    | Type                    | Default                                 | Description                  |
| ------------ | ----------------------- | --------------------------------------- | ---------------------------- |
| `contractId` | `string`                | **Required**                            | Contract address (C-address) |
| `sorobanRpc` | `string`                | `'https://soroban-testnet.stellar.org'` | Soroban RPC endpoint         |
| `network`    | `'TESTNET' \| 'PUBLIC'` | `'TESTNET'`                             | Stellar network              |

### Return Value

```typescript
interface SorobanContractReturn {
  callFunction: (name: string, args: TypedArg[]) => Promise<unknown>;
  simulateContractCall: (
    name: string,
    args: TypedArg[]
  ) => Promise<SimulateContractCallResult>;
  buildInvokeXDR: (name: string, args: TypedArg[]) => Promise<string>;
  submitInvokeWithSecret: (
    xdr: string,
    secret: string
  ) => Promise<rpc.Api.SendTransactionResponse>;
  loading: boolean;
  error?: Error | null;
}

interface SimulateContractCallResult {
  result: unknown;
  minResourceFee: string;
  latestLedger: number;
}
```

The RPC endpoint defaults to `https://soroban-testnet.stellar.org`; `network` defaults to `TESTNET`. `simulateContractCall()` returns the decoded value, minimum resource fee in stroops, and ledger used for simulation.

## Methods

### callFunction()

Call a contract function in read-only mode (simulation).

```tsx
// Simple call
const balance = await callFunction('balance', [
  { value: 'GABC123...', type: 'address' },
]);

// With multiple arguments
const result = await callFunction('transfer', [
  { value: 'GABC123...', type: 'address' },
  { value: 'GDEF456...', type: 'address' },
  { value: 1000n, type: 'u128' },
]);
```

The hook accepts tagged `{ value, type }` arguments for `u32`, `i32`, `u64`, `i64`, `u128`, `i128`, `bool`, `string`, `symbol`, `address`, `bytes`, `vec`, `map`, `enum`, `timepoint`, and `duration`. It also auto-detects common JavaScript values. `callFunction` returns `unknown`; narrow the decoded value before using it. Large integers decode to `bigint`, vectors to arrays, and XDR maps to plain objects.

### buildInvokeXDR()

Build an unsigned contract invocation XDR.

```tsx
async function createMintXdr(
  recipient: string,
  buildInvokeXDR: (name: string, args: TypedArg[]) => Promise<string>
) {
  return buildInvokeXDR('mint', [
    { value: recipient, type: 'address' },
    { value: 1000n, type: 'u128' },
  ]);
}
```

`buildInvokeXDR()` returns an unsigned transaction. Sign it with a wallet adapter before submitting it through Soroban RPC.

### submitInvokeWithSecret()

**DEV-ONLY**: Sign and submit contract invocation.

```tsx
async function submitForDevelopment(
  submitInvokeWithSecret: (
    xdr: string,
    secret: string
  ) => Promise<rpc.Api.SendTransactionResponse>,
  signedXdr: string,
  developmentSecret: string
) {
  const result = await submitInvokeWithSecret(signedXdr, developmentSecret);
  console.log('RPC send status:', result.status);
}
```

> **Warning**: This method signs with a secret key and is for development only. Never handle secret keys in production client code.

## Advanced Examples

### Complex Contract Calls

```tsx
// Call with Address type
import { Address } from '@stellar/stellar-sdk';

const recipient = new Address('GABC123...');
const result = await callFunction('transfer', [recipient, 1000]);
```

### Handling Contract Events

```tsx
const { callFunction } = useSorobanContract({ contractId });

const result = await callFunction('emit_event', ['test_event']);

// Listen for events with useSorobanEvents hook
```

### Error Handling

For shared recovery patterns across hooks, see [Hook Error Handling](/docs/guides/hook-error-handling).

```tsx
const { callFunction, error } = useSorobanContract({ contractId });

try {
  const result = await callFunction('get_data', []);
} catch (err) {
  if (error?.message.includes('not found')) {
    console.log('Contract not deployed');
  }
}
```

## Type Conversion

### JavaScript to XDR

```tsx
// String
await callFunction('set_name', ['Alice']); // → ScvString

// Number
await callFunction('set_count', [42]); // → ScvI32

// Boolean
await callFunction('set_active', [true]); // → ScvBool

// Array
await callFunction('set_list', [[1, 2, 3]]); // → ScvVec

// Object
await callFunction('set_data', [{ key: 'value' }]); // → ScvMap
```

### XDR to JavaScript

```tsx
const result = await callFunction('get_data', []);

// ScvString → string
// ScvI32 → number
// ScvBool → boolean
// ScvVec → Array
// ScvMap → Object
```

## Best Practices

### 1. Cache Contract Instances

```tsx
const contractConfig = useMemo(
  () => ({
    contractId: 'CDLZ...',
    network: 'TESTNET' as const,
  }),
  []
);

const contract = useSorobanContract(contractConfig);
```

### 2. Handle Loading States

```tsx
function ContractLoading({ contractId }: { contractId: string }) {
  const { callFunction, loading } = useSorobanContract({ contractId });

  if (loading) return <Spinner />;
  return <button onClick={() => callFunction('get_data', [])}>Read</button>;
}
```

### 3. Validate Contract Responses

```tsx
const result = await callFunction('get_balance', [address]);

if (typeof result !== 'number') {
  throw new Error('Invalid balance returned');
}
```
