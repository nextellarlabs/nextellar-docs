# useOfferBook

The `useOfferBook` hook queries one Stellar DEX buying/selling asset pair and returns bids, asks, loading/error state, and manual refresh controls.

<Note>
  **Ships in:** TypeScript `default` and `defi` and JavaScript `js-template` and
  `js-defi`
  <br />
  Not in your scaffold? Run `nextellar add defi`
</Note>

## Features

- **Order Book Data**: Fetch bids and asks for one asset pair
- **Polling**: Optional refresh interval, disabled by default
- **Configuration**: Uses the `WalletProvider` Horizon URL when no URL is passed

## Basic Usage

```tsx
import { useOfferBook } from '@/hooks/useOfferBook';

export default function OrderBook() {
  const { bids, asks, loading, error, refresh } = useOfferBook(
    { code: 'USDC', issuer: 'GA5Z...' },
    'XLM',
    { pollIntervalMs: 5000 }
  );

  if (loading) return <div>Loading order book...</div>;
  if (error)
    return (
      <div>
        {error.message} <button onClick={refresh}>Retry</button>
      </div>
    );

  return (
    <div>
      <h3>Bids</h3>
      {bids.map((bid, i) => (
        <div key={i}>
          {bid.price} - {bid.amount}
        </div>
      ))}

      <h3>Asks</h3>
      {asks.map((ask, i) => (
        <div key={i}>
          {ask.price} - {ask.amount}
        </div>
      ))}
    </div>
  );
}
```

## API Reference

### Parameters

```typescript
function useOfferBook(
  buying: Asset,
  selling: Asset,
  opts?: { horizonUrl?: string; limit?: number; pollIntervalMs?: number | null }
): OfferBookState;

type Asset = 'XLM' | { code: string; issuer: string };

interface OfferBookState {
  bids: Offer[];
  asks: Offer[];
  loading: boolean;
  refresh: () => Promise<void>;
  stopPolling: () => void;
  error: Error | null;
}
```

| Option                | Type             | Default                                             | Description                             |
| --------------------- | ---------------- | --------------------------------------------------- | --------------------------------------- |
| `opts.horizonUrl`     | `string`         | Provider config, then `https://horizon.stellar.org` | Horizon endpoint.                       |
| `opts.limit`          | `number`         | `20`                                                | Offers returned per side.               |
| `opts.pollIntervalMs` | `number \| null` | `null`                                              | Poll interval; `null` disables polling. |

## Examples

### Get Current Price

```tsx
type Asset = 'XLM' | { code: string; issuer: string };

export function BestAsk({
  buying,
  selling,
}: {
  buying: Asset;
  selling: Asset;
}) {
  const { asks, bids } = useOfferBook(buying, selling);

  return (
    <p>
      Best bid: {bids[0]?.price ?? '—'}; best ask: {asks[0]?.price ?? '—'}
    </p>
  );
}
```

### Calculate Order Book Depth

```tsx
type Asset = 'XLM' | { code: string; issuer: string };

export function OrderBookDepth({
  buying,
  selling,
}: {
  buying: Asset;
  selling: Asset;
}) {
  const { bids, asks } = useOfferBook(buying, selling);
  const bidVolume = bids.reduce((sum, bid) => sum + Number(bid.amount), 0);
  const askVolume = asks.reduce((sum, ask) => sum + Number(ask.amount), 0);

  return (
    <p>
      Bid volume: {bidVolume}; ask volume: {askVolume}
    </p>
  );
}
```

### Live Updates

Pass `pollIntervalMs` to enable polling; the hook clears its interval when the component unmounts.

```tsx
import { useOfferBook } from '@/hooks/useOfferBook';

type Asset = 'XLM' | { code: string; issuer: string };

export function LiveOrderBook({
  buying,
  selling,
}: {
  buying: Asset;
  selling: Asset;
}) {
  const { bids, asks, loading, error, refresh } = useOfferBook(
    buying,
    selling,
    { pollIntervalMs: 5000 }
  );

  if (loading && bids.length === 0 && asks.length === 0) {
    return <p>Loading order book...</p>;
  }

  return (
    <section aria-live="polite">
      {error && <p role="alert">Unable to update: {error.message}</p>}
      <p>{bids.length + asks.length} offers, updated every 5 seconds</p>
      <button type="button" onClick={() => void refresh()} disabled={loading}>
        Refresh now
      </button>
    </section>
  );
}
```

## Error Handling

### Empty Market

An empty bid or ask side is a valid state. Render the book with zero depth instead of treating it as a failure.

### Invalid Pair

Validate the assets before querying the order book so malformed pairs fail before the request is sent.

### Network Failures

If Horizon is unavailable, keep the last known book visible and expose `refresh()` so the user can retry.

```tsx
type Asset = 'XLM' | { code: string; issuer: string };

export function OrderBookRetry({
  buying,
  selling,
}: {
  buying: Asset;
  selling: Asset;
}) {
  const { error, refresh } = useOfferBook(buying, selling);
  if (!error) return null;

  return (
    <div>
      <p>{error.message}</p>
      <button type="button" onClick={() => void refresh()}>
        Retry
      </button>
    </div>
  );
}
```

## Best Practices

1. **Cache Results**: Use SWR or React Query for caching
2. **Limit Refresh Rate**: Don't refresh too frequently
3. **Handle Empty Books**: Show message when no offers exist
4. **Validate Assets**: Ensure asset codes and issuers are correct
