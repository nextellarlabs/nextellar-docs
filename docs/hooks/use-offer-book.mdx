# useOfferBook

The `useOfferBook` hook queries Stellar's decentralized exchange (DEX) order books, enabling trading interfaces and price discovery.

**Available in templates:** `default`, `defi`, `js`

<Note>
  **Ships in:** default, defi, js
  <br />
  Not in your scaffold? Run `nextellar add defi`
</Note>

## Features

- **Order Book Data**: Fetch bids and asks for trading pairs
- **Price Discovery**: Get current market prices
- **Depth Analysis**: Analyze order book depth
- **Real-Time Updates**: Optional live order book updates

## Basic Usage

```tsx
import { useOfferBook } from '@/hooks/useOfferBook';

export default function OrderBook() {
  const { bids, asks, loading } = useOfferBook(
    { code: 'XLM' },
    { code: 'USDC', issuer: 'GA5Z...' }
  );

  if (loading) return <div>Loading order book...</div>;

  return (
    <div>
      <h3>Bids</h3>
      {bids.map((bid, i) => (
        <div key={i}>
          {bid.price} - {bid.amount}
        </div>
      ))}

      <h3>Asks</h3>
      {asks.map((ask, i) => (
        <div key={i}>
          {ask.price} - {ask.amount}
        </div>
      ))}
    </div>
  );
}
```

## API Reference

### Parameters

```typescript
useOfferBook(
  sellingAsset: { code: string; issuer?: string },
  buyingAsset: { code: string; issuer?: string },
  options?: {
    horizonUrl?: string;
    refreshIntervalMs?: number;
  }
): OfferBookState
```

| Parameter           | Type                                | Default                          | Description                                                               |
| ------------------- | ----------------------------------- | -------------------------------- | ------------------------------------------------------------------------- |
| `sellingAsset`      | `{ code: string; issuer?: string }` | **Required**                     | Asset being sold (native assets have no `issuer`; no `type` field is used) |
| `buyingAsset`       | `{ code: string; issuer?: string }` | **Required**                     | Asset being bought (native assets have no `issuer`; no `type` field is used) |
| `horizonUrl`        | `string`                            | WalletProvider config or testnet | Horizon URL                                                               |
| `refreshIntervalMs` | `number`                            | — (no polling by default)        | Poll interval in milliseconds for built-in auto-refresh                   |

### Return Value

```typescript
interface OfferBookState {
  bids: Array<{ price: string; amount: string }>;
  asks: Array<{ price: string; amount: string }>;
  loading: boolean;
  error: Error | null;
  refresh: () => Promise<void>;
}
```

## Examples

### Get Current Price

```tsx
const { bids, asks } = useOfferBook(
  { code: 'XLM' },
  { code: 'USDC', issuer: 'GA5Z...' }
);

const bestBid = bids[0] ? parseFloat(bids[0].price) : 0;
const bestAsk = asks[0] ? parseFloat(asks[0].price) : 0;
const midPrice = bestBid && bestAsk ? (bestBid + bestAsk) / 2 : 0;
const spread = bestBid ? ((bestAsk - bestBid) / bestBid) * 100 : 0;

return (
  <div>
    <p>Price: ${midPrice}</p>
    <p>Spread: {spread}%</p>
  </div>
);
```

### Calculate Order Book Depth

```tsx
const { bids, asks } = useOfferBook(
  { code: 'XLM' },
  { code: 'USDC', issuer: 'GA5Z...' }
);

const totalBidVolume = bids.reduce(
  (sum, bid) => sum + parseFloat(bid.amount),
  0
);
const totalAskVolume = asks.reduce(
  (sum, ask) => sum + parseFloat(ask.amount),
  0
);

console.log('Buy pressure:', totalBidVolume);
console.log('Sell pressure:', totalAskVolume);
```

### Live Updates

Refresh the order book on an interval and clean up the timer when the component unmounts (or pass `refreshIntervalMs` in options for built-in polling):

```tsx
import { useEffect } from 'react';
import { useOfferBook } from '@/hooks/useOfferBook';

export function LiveOrderBook({ selling, buying }) {
  const { bids, asks, loading, error, refresh } = useOfferBook(
    selling,
    buying
  );

  useEffect(() => {
    const interval = window.setInterval(() => {
      void refresh();
    }, 5000);

    return () => window.clearInterval(interval);
  }, [refresh]);

  if (loading && bids.length === 0 && asks.length === 0) {
    return <p>Loading order book...</p>;
  }

  return (
    <section aria-live="polite">
      {error && <p role="alert">Unable to update: {error.message}</p>}
      <p>{bids.length + asks.length} offers, updated every 5 seconds</p>
      <button type="button" onClick={() => void refresh()} disabled={loading}>
        Refresh now
      </button>
    </section>
  );
}
```

## Error Handling

### Empty Market

An empty bid or ask side is a valid state. Render the book with zero depth instead of treating it as a failure.

### Invalid Pair

Validate the assets before querying the order book so malformed pairs fail before the request is sent. Native assets are shaped `{ code: 'XLM' }` (no `issuer`, no `type` field); non-native assets require both `code` and `issuer`.

### Network Failures

If Horizon is unavailable, keep the last known book visible and expose `refresh()` so the user can retry.

```tsx
if (error) {
  return (
    <div>
      <p>{error.message}</p>
      <button onClick={refresh}>Retry</button>
    </div>
  );
}
```

## Best Practices

1. **Cache Results**: Use SWR or React Query for caching
2. **Limit Refresh Rate**: Don't refresh too frequently
3. **Handle Empty Books**: Show message when no offers exist
4. **Validate Assets**: Ensure asset codes and issuers are correct
