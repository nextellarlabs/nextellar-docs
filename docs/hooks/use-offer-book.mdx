# useOfferBook

The `useOfferBook` hook queries Stellar's decentralized exchange (DEX) order books, enabling trading interfaces and price discovery.

<Note>
  **Ships in:** default, js, defi, js-defi
  <br />
  Not in your scaffold? Run `nextellar add defi`
</Note>

## Features

- **Order Book Data**: Fetch bids and asks for a trading pair
- **Price Discovery**: Derive market prices from the top of the book
- **Depth Analysis**: Analyze order book depth
- **Live Updates**: Optional built-in polling via `pollIntervalMs`
- **Multiple Pairs**: Call the hook once per trading pair

## Basic Usage

```tsx
import { useOfferBook } from '@/hooks/useOfferBook';

export default function OrderBook() {
  const { bids, asks, loading } = useOfferBook(
    'XLM',
    { code: 'USDC', issuer: 'GA5Z...' },
    { limit: 20 }
  );

  if (loading) return <div>Loading order book...</div>;

  return (
    <div>
      <h3>Bids</h3>
      {bids.map((bid, i) => (
        <div key={i}>
          {bid.price} - {bid.amount}
        </div>
      ))}

      <h3>Asks</h3>
      {asks.map((ask, i) => (
        <div key={i}>
          {ask.price} - {ask.amount}
        </div>
      ))}
    </div>
  );
}
```

## API Reference

### Parameters

`useOfferBook` takes the two assets as positional arguments, followed by an options object:

```typescript
useOfferBook(
  buying: Asset,
  selling: Asset,
  opts?: {
    horizonUrl?: string;
    limit?: number;
    pollIntervalMs?: number | null;
  }
): OfferBookState
```

An `Asset` is either the literal string `'XLM'` for the native asset or an object with `code` and `issuer` for issued assets:

```typescript
type Asset = 'XLM' | { code: string; issuer: string };
```

| Parameter        | Type             | Default                                                     | Description                                                                                                          |
| ---------------- | ---------------- | ----------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| `buying`         | `Asset`          | **Required**                                                | Asset being bought (first positional argument)                                                                       |
| `selling`        | `Asset`          | **Required**                                                | Asset being sold (second positional argument)                                                                        |
| `horizonUrl`     | `string`         | Provider's `horizonUrl`, else `https://horizon.stellar.org` | Horizon endpoint to query. When used inside a `WalletProvider`, the provider's `horizonUrl` is used as the fallback. |
| `limit`          | `number`         | `20`                                                        | Number of offers per side                                                                                            |
| `pollIntervalMs` | `number \| null` | `null`                                                      | When set, the hook refetches the book on this interval (in milliseconds)                                             |

### Return Value

```typescript
interface OfferBookState {
  bids: Offer[];
  asks: Offer[];
  loading: boolean;
  refresh: () => Promise<void>;
  stopPolling: () => void;
  error: Error | null;
}

type Offer = {
  price: string;
  amount: string;
  seller: string;
  buying: Asset;
  selling: Asset;
};
```

The hook does not return `midPrice` or `spread` — derive them from `bids` and `asks` as shown in [Get Current Price](#get-current-price).

## Examples

### Get Current Price

Derive the mid price and spread from the top of the book:

```tsx
const { bids, asks } = useOfferBook('XLM', {
  code: 'USDC',
  issuer: 'GA5Z...',
});

const bestBid = bids.length > 0 ? parseFloat(bids[0].price) : null;
const bestAsk = asks.length > 0 ? parseFloat(asks[0].price) : null;
const midPrice =
  bestBid !== null && bestAsk !== null ? (bestBid + bestAsk) / 2 : null;
const spread = bestBid !== null && bestAsk !== null ? bestAsk - bestBid : null;

return (
  <div>
    <p>Price: {midPrice !== null ? `$${midPrice}` : '—'}</p>
    <p>Spread: {spread ?? '—'}</p>
  </div>
);
```

### Calculate Order Book Depth

```tsx
const { bids, asks } = useOfferBook('XLM', {
  code: 'USDC',
  issuer: 'GA5Z...',
});

const totalBidVolume = bids.reduce(
  (sum, bid) => sum + parseFloat(bid.amount),
  0
);
const totalAskVolume = asks.reduce(
  (sum, ask) => sum + parseFloat(ask.amount),
  0
);

console.log('Buy pressure:', totalBidVolume);
console.log('Sell pressure:', totalAskVolume);
```

### Live Updates

Pass `pollIntervalMs` to have the hook refetch the book on an interval. The timer is cleared automatically when the component unmounts; call `stopPolling()` to stop it earlier:

```tsx
import { useOfferBook } from '@/hooks/useOfferBook';

// The hook doesn't export its Asset type — derive it from the signature
type Asset = Parameters<typeof useOfferBook>[0];

export function LiveOrderBook({
  buying,
  selling,
}: {
  buying: Asset;
  selling: Asset;
}) {
  const { bids, asks, loading, error, refresh, stopPolling } = useOfferBook(
    buying,
    selling,
    { pollIntervalMs: 5000 }
  );

  if (loading && bids.length === 0 && asks.length === 0) {
    return <p>Loading order book...</p>;
  }

  return (
    <section aria-live="polite">
      {error && <p role="alert">Unable to update: {error.message}</p>}
      <p>{bids.length + asks.length} offers, refreshed every 5 seconds</p>
      <button type="button" onClick={() => void refresh()} disabled={loading}>
        Refresh now
      </button>
      <button type="button" onClick={stopPolling}>
        Stop live updates
      </button>
    </section>
  );
}
```

## Error Handling

### Empty Market

An empty bid or ask side is a valid state. Render the book with zero depth instead of treating it as a failure.

### Invalid Pair

Validate the assets before querying the order book so malformed pairs fail before the request is sent.

### Network Failures

If Horizon is unavailable, keep the last known book visible and expose `refresh()` so the user can retry.

```tsx
if (error) {
  return (
    <div>
      <p>{error.message}</p>
      <button onClick={refresh}>Retry</button>
    </div>
  );
}
```

## Best Practices

1. **Cache Results**: Use SWR or React Query for caching
2. **Limit Refresh Rate**: Don't refresh too frequently
3. **Handle Empty Books**: Show message when no offers exist
4. **Validate Assets**: Ensure asset codes and issuers are correct
