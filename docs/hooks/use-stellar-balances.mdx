# useStellarBalances

The `useStellarBalances` hook provides real-time balance tracking for Stellar accounts, including XLM and all custom assets with automatic polling capabilities.

**Available in all six template variants:** `default`, `js-template`, `minimal`, `js-minimal`, `defi`, and `js-defi`.

<Note>
  **Ships in:** all TypeScript and JavaScript variants
  <br />
  Not in your scaffold? Run `nextellar add balances`
</Note>

## Features

- **Real-Time Balances**: Automatic balance fetching with race condition safety
- **Polling**: Optional polling with configurable intervals (minimum 5000 ms)
- **All Assets**: XLM and custom asset support via Horizon
- **Unfunded Accounts**: Gracefully handles new accounts (404 → empty balances)
- **Auto-Config**: Uses WalletProvider settings as fallback
- **Polling Cleanup**: Clears polling timers when the key changes or component unmounts

## Basic Usage

```tsx
import { useStellarBalances } from '@/hooks/useStellarBalances';

export default function BalanceDisplay({ publicKey }: { publicKey: string }) {
  const { balances, loading, error, refresh } = useStellarBalances(publicKey);

  if (loading && balances.length === 0) return <div>Loading balances...</div>;
  if (error)
    return (
      <div>
        Error: {error.message} <button onClick={refresh}>Retry</button>
      </div>
    );

  return (
    <div>
      {balances.length === 0 ? (
        <p>No balances found. Account may need funding.</p>
      ) : (
        balances.map((balance, index) => (
          <div key={index}>
            {balance.asset_type === 'native' ? 'XLM' : balance.asset_code}:{' '}
            {balance.balance}
          </div>
        ))
      )}
      <button onClick={refresh}>Refresh</button>
    </div>
  );
}
```

## API Reference

### Parameters

```typescript
useStellarBalances(
  publicKey?: string | null,
  options?: {
    horizonUrl?: string;
    pollIntervalMs?: number | null;
  }
): StellarBalancesState;
```

| Parameter                | Type                          | Default                             | Description                                                                                                                   |
| ------------------------ | ----------------------------- | ----------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `publicKey`              | `string \| null \| undefined` | `undefined`                         | Account public key. If omitted or empty, balances clear and no request runs.                                                  |
| `options.horizonUrl`     | `string`                      | Wallet config, then testnet Horizon | Horizon server URL.                                                                                                           |
| `options.pollIntervalMs` | `number \| null`              | `undefined`                         | Poll interval in ms. Positive values below 5000 are clamped to 5000; unset, `null`, zero, or negative values disable polling. |

### Return Value

```typescript
interface StellarBalancesState {
  balances: AssetBalance[];
  loading: boolean;
  error?: Error | null;
  refresh: () => Promise<void>;
  stopPolling: () => void;
}

interface AssetBalance {
  asset_type: string;
  asset_code?: string; // Only for non-native assets
  asset_issuer?: string; // Only for non-native assets
  balance: string; // Stringified balance value
  limit?: string; // Trustline limit; absent for native
}
```

**Return value details:**

- `balances`: Array of asset balances; empty if account is unfunded or has no trustlines
- `loading`: `true` while a request is in progress; starts as `false`
- `error`: `null` on success; populated with error message on failure (e.g., network, invalid key)
- `refresh`: Async function to manually trigger a balance fetch and update state
- `stopPolling`: Stops the active polling interval without disabling manual refresh

With no public key, balances are empty, `loading` is false, and `error` is null. A Horizon 404 is treated as an unfunded account and returns an empty balance list. Other request failures set `error` and preserve the last successful balance data.

## Examples

### With Auto-Refresh (Polling)

```tsx
import { useStellarBalances } from '@/hooks/useStellarBalances';

export function LiveBalance({ publicKey }: { publicKey: string }) {
  const { balances, loading, error } = useStellarBalances(publicKey, {
    pollIntervalMs: 10000, // Poll every 10 seconds
  });

  if (loading && balances.length === 0) return <div>Loading...</div>;
  if (error) return <div>Error: {error.message}</div>;

  return (
    <div>
      {balances.map((b, i) => (
        <p key={i}>
          {b.asset_type === 'native' ? 'XLM' : b.asset_code}: {b.balance}
        </p>
      ))}
    </div>
  );
}
```

### Filter by Asset Type

```tsx
import { useStellarBalances } from '@/hooks/useStellarBalances';

export function AssetSelector({ publicKey }: { publicKey: string }) {
  const { balances } = useStellarBalances(publicKey);

  const xlmBalance =
    balances.find((b) => b.asset_type === 'native')?.balance ?? '0';
  const customAssets = balances.filter((b) => b.asset_type !== 'native');

  return (
    <div>
      <p>XLM: {xlmBalance}</p>
      <h3>Custom Assets:</h3>
      {customAssets.map((asset, i) => (
        <p key={i}>
          {asset.balance} {asset.asset_code}
        </p>
      ))}
    </div>
  );
}
```

### Manual Refresh After Transaction

```tsx
import { useStellarBalances } from '@/hooks/useStellarBalances';
import { useStellarWallet } from '@/hooks/useStellarWallet';

export function PaymentWithRefresh({
  to,
  amount,
}: {
  to: string;
  amount: string;
}) {
  const { publicKey, sendPayment } = useStellarWallet();
  const { refresh } = useStellarBalances(publicKey);

  const handleSend = async () => {
    if (!sendPayment) return;

    try {
      await sendPayment({ to, amount, asset: 'XLM' });
      await refresh(); // Update balances after payment
    } catch (e) {
      console.error('Payment failed:', e);
    }
  };

  return <button onClick={handleSend}>Send {amount} XLM</button>;
}
```

### With Custom Horizon URL

```tsx
import { useStellarBalances } from '@/hooks/useStellarBalances';

export function MainnetBalances({ publicKey }: { publicKey: string }) {
  // Override provider config for this component
  const { balances, loading } = useStellarBalances(publicKey, {
    horizonUrl: 'https://horizon.stellar.org', // Use mainnet
    pollIntervalMs: 30000,
  });

  if (loading) return <div>Syncing...</div>;
  return <div>{balances.length} assets found</div>;
}
```

## Auto-Config Pattern

The hook automatically uses `WalletProvider` config as fallback:

```tsx
import { WalletProvider } from '@/contexts/WalletProvider';
import { useStellarBalances } from '@/hooks/useStellarBalances';

// Provider sets default Horizon URL
export function App() {
  return (
    <WalletProvider horizonUrl="https://horizon.stellar.org">
      <BalanceWidget />
    </WalletProvider>
  );
}

// Hook uses provider's horizonUrl automatically
function BalanceWidget() {
  const { publicKey } = useStellarWallet();
  const { balances } = useStellarBalances(publicKey);
  // Uses mainnet URL from provider!
  return <div>{balances.length} balances</div>;
}
```

## Error Handling

### Unfunded Accounts

New accounts without initial XLM funding return a 404 from Horizon. The hook catches this gracefully:

```tsx
import { useStellarBalances } from '@/hooks/useStellarBalances';

export function AccountStatus({ publicKey }: { publicKey: string }) {
  const { balances, error } = useStellarBalances(publicKey);

  if (error && error.message.includes('404')) {
    return <p>Account needs funding. Send XLM to: {publicKey}</p>;
  }

  if (balances.length === 0 && !error) {
    return <p>No balances yet (account may be unfunded)</p>;
  }

  return <p>Balances loaded successfully</p>;
}
```

### Transient Network Failures

If Horizon is temporarily unavailable, keep the last successful data on screen and expose `refresh()` so users can retry:

```tsx
export function BalanceWithRetry({ publicKey }: { publicKey: string }) {
  const { balances, error, refresh } = useStellarBalances(publicKey);

  if (error) {
    return (
      <div className="error">
        <p>{error.message}</p>
        <button onClick={refresh}>Retry</button>
      </div>
    );
  }

  return (
    <div>
      <p>{balances.length} assets</p>
      <button onClick={refresh}>Refresh</button>
    </div>
  );
}
```

### Invalid Public Key

Malformed public keys are validated before making HTTP requests:

```tsx
// This will produce an error immediately (invalid G-address format)
const { error } = useStellarBalances('INVALID-KEY');
```

## Best Practices

1. **Set Realistic Poll Intervals**: Positive poll intervals are clamped to at least 5 seconds.
2. **Handle Null Public Keys**: Always pass `publicKey || null` when account is not connected yet
3. **Check Asset Type**: Use `asset_type === 'native'` to distinguish XLM from custom assets
4. **Combine with useStellarWallet**: Pair with wallet hook to get the public key
5. **Manual Refresh After Transactions**: Call `refresh()` after sending payments to show updated balances immediately
6. **Cleanup on Unmount**: The hook handles timer cleanup automatically via useEffect
7. **Avoid Overlapping Requests**: A request-in-flight guard skips duplicate requests; requests are not aborted on key changes.
