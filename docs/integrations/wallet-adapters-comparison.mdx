# Wallet Adapter Comparison

Freighter and xBull are both browser-extension wallets that work with the Stellar Wallets Kit used by Nextellar. They share the same connection pattern, but they serve slightly different audiences.

## Comparison

| Area | Freighter | xBull |
| --- | --- | --- |
| Best fit | General Stellar users and onboarding flows | Power users, DeFi workflows, and advanced asset management |
| Install model | Browser extension | Browser extension |
| Typical default | Good first default for broad audiences | Good alternate option for trading-heavy apps |
| Network selection | User selects testnet or mainnet in the extension | User selects testnet or mainnet in the extension |
| Signing flow | Extension permission prompt, then transaction approval | Extension permission prompt, then transaction approval |
| Nextellar setup | `FreighterModule` in `stellar-wallets-kit.ts` | `xBullModule` in `stellar-wallets-kit.ts` |
| UX guidance | Show as the first recommended wallet for most users | Offer alongside Freighter when the app targets DeFi users |

## Setup: Freighter

```typescript
import {
  FREIGHTER_ID,
  FreighterModule,
  StellarWalletsKit,
  WalletNetwork,
} from '@creit.tech/stellar-wallets-kit';

export const kit = new StellarWalletsKit({
  network: WalletNetwork.TESTNET,
  selectedWalletId: FREIGHTER_ID,
  modules: [new FreighterModule()],
});
```

Use Freighter as the default when the app has a broad audience, because many Stellar users already recognize it.

## Setup: xBull

```typescript
import {
  StellarWalletsKit,
  WalletNetwork,
  xBullModule,
} from '@creit.tech/stellar-wallets-kit';

export const kit = new StellarWalletsKit({
  network: WalletNetwork.TESTNET,
  modules: [new xBullModule()],
});
```

Use xBull as a visible option when the app includes DeFi, DEX, or asset-management flows where users may already prefer that wallet.

## Supporting both

Most apps should expose both adapters through the same wallet kit instance:

```typescript
import {
  FREIGHTER_ID,
  FreighterModule,
  StellarWalletsKit,
  WalletNetwork,
  xBullModule,
} from '@creit.tech/stellar-wallets-kit';

export const kit = new StellarWalletsKit({
  network: WalletNetwork.TESTNET,
  selectedWalletId: FREIGHTER_ID,
  modules: [new FreighterModule(), new xBullModule()],
});
```

Keep the rest of the app wallet-agnostic. Components should call the generated wallet hook or provider instead of branching on the adapter unless a wallet-specific recovery message is needed.
