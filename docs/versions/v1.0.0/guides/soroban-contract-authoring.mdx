# Comprehensive Soroban Smart Contract Authoring Guide

Soroban is Stellar's WebAssembly-based smart contract platform, authored in Rust using the `soroban-sdk`. This guide covers everything needed to build, test, optimize, and deploy production-grade Soroban contracts for Nextellar applications.

---

## 1. Project Layout & Configuration

A standard Soroban smart contract repository requires a Cargo workspace structure configured to target WASM (`wasm32-unknown-unknown`).

### Directory Layout

```
my-soroban-contract/
├── Cargo.toml
└── contracts/
    └── vault/
        ├── Cargo.toml
        └── src/
            ├── lib.rs
            └── test.rs
```

### Root Cargo.toml

```toml
[workspace]
members = ["contracts/*"]
resolver = "2"

[profile.release]
opt-level = "z"
overflow-checks = true
debug = false
strip = "symbols"
debug-assertions = false
panic = "abort"
codegen-units = 1
```

### Contract Cargo.toml (`contracts/vault/Cargo.toml`)

```toml
[package]
name = "soroban-vault-contract"
version = "0.1.0"
edition = "2021"

[lib]
crate-type = ["cdylib"]

[dependencies]
soroban-sdk = "21.0.0"

[dev-dependencies]
soroban-sdk = { version = "21.0.0", features = ["testutils"] }
```

## 2. Complete Sample Rust Contract

Below is a complete, production-ready **Vault Contract** featuring deposit, withdrawal, authorization checks (`require_auth`), and explicit instance/persistent storage handling.

### `contracts/vault/src/lib.rs`

```rust
#![no_std]
use soroban_sdk::{contract, contractimpl, contracttype, symbol_short, Address, Env, Symbol};

const BALANCE: Symbol = symbol_short!("BALANCE");
const ADMIN: Symbol = symbol_short!("ADMIN");

#[contracttype]
pub enum DataKey {
    Balance(Address),
    Admin,
}

#[contract]
pub struct VaultContract;

#[contractimpl]
impl VaultContract {
    /// Initialize the vault with an admin address
    pub fn initialize(env: Env, admin: Address) {
        if env.storage().instance().has(&DataKey::Admin) {
            panic!("Already initialized");
        }
        env.storage().instance().set(&DataKey::Admin, &admin);
    }

    /// Deposit funds into the vault for a given user
    pub fn deposit(env: Env, from: Address, amount: i128) {
        from.require_auth();
        if amount <= 0 {
            panic!("Amount must be positive");
        }

        let key = DataKey::Balance(from.clone());
        let current_balance: i128 = env.storage().persistent().get(&key).unwrap_or(0);
        let new_balance = current_balance.checked_add(amount).expect("Balance overflow");

        env.storage().persistent().set(&key, &new_balance);

        // Extend storage TTL so the balance record doesn't get archived
        env.storage().persistent().extend_ttl(&key, 100_000, 300_000);
    }

    /// Withdraw funds from the vault
    pub fn withdraw(env: Env, from: Address, amount: i128) {
        from.require_auth();
        if amount <= 0 {
            panic!("Amount must be positive");
        }

        let key = DataKey::Balance(from.clone());
        let current_balance: i128 = env.storage().persistent().get(&key).unwrap_or(0);

        if current_balance < amount {
            panic!("Insufficient vault balance");
        }

        let new_balance = current_balance - amount;
        env.storage().persistent().set(&key, &new_balance);
    }

    /// Query balance of an account
    pub fn get_balance(env: Env, from: Address) -> i128 {
        let key = DataKey::Balance(from);
        env.storage().persistent().get(&key).unwrap_or(0)
    }
}

mod test;
```

## 3. Unit & Integration Testing in Rust

Soroban provides isolated host environment emulation (`soroban_sdk::Env`) for unit testing contract logic without requiring a live node.

### `contracts/vault/src/test.rs`

```rust
#![cfg(test)]

use super::*;
use soroban_sdk::testutils::Address as _;
use soroban_sdk::Env;

#[test]
fn test_deposit_and_withdraw() {
    let env = Env::default();
    env.mock_all_auths();

    let contract_id = env.register_contract(None, VaultContract);
    let client = VaultContractClient::new(&env, &contract_id);

    let admin = Address::generate(&env);
    let user = Address::generate(&env);

    client.initialize(&admin);

    // Initial balance zero
    assert_eq!(client.get_balance(&user), 0);

    // Deposit 500 units
    client.deposit(&user, &500);
    assert_eq!(client.get_balance(&user), 500);

    // Withdraw 200 units
    client.withdraw(&user, &200);
    assert_eq!(client.get_balance(&user), 300);
}

#[test]
#[should_panic(expected = "Insufficient vault balance")]
fn test_withdraw_insufficient_funds() {
    let env = Env::default();
    env.mock_all_auths();

    let contract_id = env.register_contract(None, VaultContract);
    let client = VaultContractClient::new(&env, &contract_id);

    let user = Address::generate(&env);
    client.deposit(&user, &100);
    client.withdraw(&user, &200); // Panic expected
}
```

## 4. Build, Optimization, and Deployment Pipeline

### Step 1: Install Wasm Target

```bash
rustup target add wasm32-unknown-unknown
```

### Step 2: Build Contract

```bash
cargo build --target wasm32-unknown-unknown --release
```

### Step 3: Optimize WASM Binary

Use `stellar-cli` (or `soroban-cli`) to minify the output WebAssembly file before deployment:

```bash
stellar contract optimize \
  --wasm target/wasm32-unknown-unknown/release/soroban_vault_contract.wasm \
  --out target/wasm32-unknown-unknown/release/soroban_vault_contract.optimized.wasm
```

### Step 4: Deploy to Testnet

```bash
stellar contract deploy \
  --wasm target/wasm32-unknown-unknown/release/soroban_vault_contract.optimized.wasm \
  --source Alice \
  --network testnet
```

## 5. Common Soroban Pitfalls & Best Practices

| Pitfall                           | Cause                                              | Prevention Strategy                                              |
| --------------------------------- | -------------------------------------------------- | ---------------------------------------------------------------- |
| **Storage TTL Archival**          | Persistent storage keys expire if not bumped       | Call `env.storage().persistent().extend_ttl()` periodically      |
| **Missing Auth (`require_auth`)** | Forgetting authorization checks on state mutations | Always invoke `address.require_auth()` before mutating user data |
| **Integer Overflow**              | Using plain operators (`+`, `-`) in release builds | Use checked math (`checked_add`, `checked_sub`)                  |
| **WASM Code Size Inflation**      | Including heavy std dependencies or unused traits  | Use `#![no_std]`, `opt-level = "z"`, and strip symbols           |
| **Cross-Contract Call Traps**     | Target contract panics or has invalid parameters   | Catch host errors and validate contract IDs                      |
