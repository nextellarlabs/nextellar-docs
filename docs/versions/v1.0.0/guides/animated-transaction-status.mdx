# Animated Transaction Status Transitions

Blockchain transactions take time to sign, submit, and confirm on the Stellar network. Providing fluid, animated status transitions reassures users that progress is occurring and clarifies the current lifecycle state.

---

## State Transition Flow

A robust transaction UI moves through well-defined sequential states:

```
[ Idle ]
   ↓ (user triggers action)
[ Awaiting Signature ] → (user rejects) → [ Cancelled / Idle ]
   ↓ (signed in Freighter)
[ Submitting to Horizon ]
   ↓ (ingested by ledger)
[ Confirming / Finalizing ]
   ↓
[ Success ]  OR  [ Failed / Error ]
```

### Suggested State Visuals

| State | Visual Indicator | Animation Pattern | Accessible Label |
| --- | --- | --- | --- |
| `signing` | Pulsing wallet icon | Soft pulse (scale 0.98 to 1.02) | "Waiting for wallet signature..." |
| `submitting` | Orbiting spinner or progress bar | Indeterminate rotation or linear slide | "Submitting transaction to Stellar..." |
| `confirming` | Ripple effect around status icon | Radial expansion | "Confirming transaction on ledger..." |
| `success` | Animated green checkmark | Scale up with spring / stroke draw | "Transaction confirmed successfully!" |
| `error` | Shake animation + error alert | Horizontal shake (±6px) | "Transaction failed: [error details]" |

---

## Motion Accessibility (`prefers-reduced-motion`)

Always respect users' system motion preferences. For users with vestibular motion sensitivity, replace continuous rotations and bouncing transitions with instant state updates or gentle opacity fades.

In Tailwind CSS, use `motion-reduce:animate-none` and `motion-reduce:transition-none`:

```html
<div className="animate-spin motion-reduce:animate-none rounded-full h-8 w-8 border-b-2 border-emerald-500" />
```

## React & Tailwind Implementation Example

Below is a complete, accessible component that animates transaction state transitions:

```tsx
import React from 'react';
import { CheckCircle2, AlertCircle, Loader2, KeyRound, ArrowRight } from 'lucide-react';

export type TxStatus = 'idle' | 'signing' | 'submitting' | 'confirming' | 'success' | 'error';

interface TransactionStatusCardProps {
  status: TxStatus;
  txHash?: string;
  errorMessage?: string;
  onReset?: () => void;
}

export const TransactionStatusCard: React.FC<TransactionStatusCardProps> = ({
  status,
  txHash,
  errorMessage,
  onReset,
}) => {
  if (status === 'idle') return null;

  return (
    <div
      role="status"
      aria-live="polite"
      className="p-6 bg-slate-900 border border-slate-800 rounded-xl max-w-md w-full shadow-xl transition-all duration-300 ease-in-out"
    >
      <div className="flex items-center gap-4">
        {/* Animated Icon Container */}
        <div className="relative flex items-center justify-center w-12 h-12 rounded-full bg-slate-800 shrink-0">
          {status === 'signing' && (
            <KeyRound className="w-6 h-6 text-amber-400 animate-pulse motion-reduce:animate-none" />
          )}

          {(status === 'submitting' || status === 'confirming') && (
            <Loader2 className="w-6 h-6 text-emerald-400 animate-spin motion-reduce:animate-none" />
          )}

          {status === 'success' && (
            <CheckCircle2 className="w-6 h-6 text-emerald-400 scale-110 transition-transform duration-300" />
          )}

          {status === 'error' && (
            <AlertCircle className="w-6 h-6 text-rose-400 animate-bounce motion-reduce:animate-none" />
          )}
        </div>

        {/* Status Text & Descriptions */}
        <div className="flex-1 min-w-0">
          <h4 className="text-sm font-semibold text-slate-100 capitalize">
            {status === 'signing' && 'Confirm in Wallet'}
            {status === 'submitting' && 'Broadcasting Transaction'}
            {status === 'confirming' && 'Confirming on Ledger'}
            {status === 'success' && 'Transaction Succeeded'}
            {status === 'error' && 'Transaction Failed'}
          </h4>

          <p className="text-xs text-slate-400 mt-0.5 truncate">
            {status === 'signing' && 'Please approve the prompt in Freighter.'}
            {status === 'submitting' && 'Waiting for Horizon ingestion...'}
            {status === 'confirming' && 'Waiting for ledger consensus...'}
            {status === 'success' && txHash && `Hash: ${txHash.slice(0, 8)}...${txHash.slice(-8)}`}
            {status === 'error' && (errorMessage || 'An error occurred during submission.')}
          </p>
        </div>
      </div>

      {/* Explorer Link or Retry Button */}
      {status === 'success' && txHash && (
        <div className="mt-4 pt-3 border-t border-slate-800 flex justify-end">
          <a
            href={`https://stellar.expert/explorer/public/tx/${txHash}`}
            target="_blank"
            rel="noopener noreferrer"
            className="text-xs text-emerald-400 hover:text-emerald-300 flex items-center gap-1 font-medium"
          >
            View on StellarExpert <ArrowRight className="w-3 h-3" />
          </a>
        </div>
      )}

      {status === 'error' && onReset && (
        <div className="mt-4 pt-3 border-t border-slate-800 flex justify-end">
          <button
            onClick={onReset}
            className="text-xs px-3 py-1.5 bg-slate-800 hover:bg-slate-700 text-slate-200 rounded-lg transition-colors"
          >
            Try Again
          </button>
        </div>
      )}
    </div>
  );
};
```
