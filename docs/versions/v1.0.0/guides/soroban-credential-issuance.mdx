# Soroban Credential Issuance and Verification Guide

Decentralized credential management allows issuers (such as identity providers, certification authorities, or game guilds) to grant verifiable attestations to user accounts on Stellar Soroban without storing sensitive personal data directly on-chain.

---

## Architecture Overview

1. **Issuance**: Authorized issuer signs a cryptographic claim containing holder address, credential type, expiration, and commitment hash.
2. **Storage**: Off-chain credential record held by the user; minimal state (or root hash/revocation status) stored on-chain.
3. **Verification**: Smart contract or third-party dApp validates the issuer signature, timestamp validity, and revocation index.

---

## Privacy & Security Considerations

- **Off-Chain PII**: Personal Identifiable Information (PII) must never be stored directly in contract instance storage.
- **Commitments & Hashes**: Store salted SHA-256 hashes (`BytesN<32>`) or Merkle roots on-chain.
- **Revocation Lists**: Maintain a bitmask or set of revoked credential IDs to support instant invalidation.

## Soroban Implementation Sample

```rust
#![no_std]
use soroban_sdk::{contract, contractimpl, contracttype, Address, BytesN, Env, Symbol};

#[contracttype]
#[derive(Clone, Debug, Eq, PartialEq)]
pub struct Credential {
    pub issuer: Address,
    pub holder: Address,
    pub cred_type: Symbol,
    pub subject_hash: BytesN<32>,
    pub expires_at: u64,
    pub revoked: bool,
}

#[contract]
pub struct CredentialRegistry;

#[contractimpl]
impl CredentialRegistry {
    pub fn issue_credential(
        env: Env,
        issuer: Address,
        holder: Address,
        cred_type: Symbol,
        subject_hash: BytesN<32>,
        expires_at: u64,
    ) -> BytesN<32> {
        issuer.require_auth();

        let cred = Credential {
            issuer: issuer.clone(),
            holder: holder.clone(),
            cred_type,
            subject_hash: subject_hash.clone(),
            expires_at,
            revoked: false,
        };

        let key = env.crypto().sha256(&subject_hash.to_val().into());
        env.storage().persistent().set(&key, &cred);
        key.into()
    }

    pub fn verify_credential(env: Env, cred_id: BytesN<32>, holder: Address) -> bool {
        let cred: Option<Credential> = env.storage().persistent().get(&cred_id);
        match cred {
            Some(c) => {
                let now = env.ledger().timestamp();
                !c.revoked && c.holder == holder && (c.expires_at == 0 || c.expires_at > now)
            }
            None => false,
        }
    }

    pub fn revoke_credential(env: Env, issuer: Address, cred_id: BytesN<32>) {
        issuer.require_auth();
        let mut cred: Credential = env.storage().persistent().get(&cred_id).expect("credential not found");
        assert_eq!(cred.issuer, issuer, "unauthorized issuer");
        cred.revoked = true;
        env.storage().persistent().set(&cred_id, &cred);
    }
}
```
