# Complete Hook Reference with Edge Case Coverage

This document serves as the authoritative, end-to-end reference for every React hook provided by Nextellar. It details input signatures, return types, expected runtime errors, race condition mitigations, unmount lifecycle behaviors, and concrete code patterns for edge-case resilience.

## 1. useStellarWallet

Manages wallet connectivity, account key state, multi-wallet selection (Freighter, Albedo, Lobstr, xBull), and transaction/blob signing.

### Signature & Inputs

```typescript
export interface WalletOptions {
  preferredWallet?: 'freighter' | 'albedo' | 'lobstr' | 'xbull';
  autoConnect?: boolean;
  network?: 'PUBLIC' | 'TESTNET' | 'FUTURENET';
}

export function useStellarWallet(
  options?: WalletOptions
): UseStellarWalletReturn;
```

### Outputs & Return Values

```typescript
export interface UseStellarWalletReturn {
  publicKey: string | null;
  isConnected: boolean;
  isConnecting: boolean;
  walletType: string | null;
  network: 'PUBLIC' | 'TESTNET' | 'FUTURENET';
  error: Error | null;
  connect: (walletType?: string) => Promise<string>;
  disconnect: () => Promise<void>;
  signTransaction: (
    xdr: string,
    opts?: { networkPassphrase?: string }
  ) => Promise<string>;
  signBlob: (blobHex: string) => Promise<string>;
}
```

### Error Scenarios & Edge Cases

- **Extension Not Installed**: `Error("Wallet extension 'freighter' is not installed")`.
- **User Rejected Request**: `Error("User rejected connection / signature request")`.
- **Network Mismatch**: Wallet extension is set to Testnet while application requires Public Mainnet.
- **Abrupt Disconnection**: Wallet extension gets locked or disabled during an active app session.

### Race Condition & Unmount Handling

- **Race Condition**: User clicks `connect()` multiple times in rapid succession or switches wallet providers before the first popup resolves. The hook cancels previous connection pending state and guarantees only the latest request updates `publicKey`.
- **Unmount Behavior**: If the parent component unmounts while awaiting extension authorization, internal state updates are guarded against memory leaks via active component mounted flags.

### Worked Edge Case Example

```tsx
import React, { useState } from 'react';
import { useStellarWallet } from '@/hooks/useStellarWallet';

export function WalletConnectEdgeCaseHandler() {
  const {
    publicKey,
    isConnected,
    isConnecting,
    error,
    connect,
    signTransaction,
  } = useStellarWallet({
    autoConnect: true,
    network: 'TESTNET',
  });
  const [signing, setSigning] = useState(false);
  const [txError, setTxError] = useState<string | null>(null);

  const handleSignSafely = async (unsignedXdr: string) => {
    setSigning(true);
    setTxError(null);
    try {
      const signedXdr = await signTransaction(unsignedXdr);
      return signedXdr;
    } catch (err: any) {
      if (err.message?.includes('rejected')) {
        setTxError('Transaction signing was cancelled by user.');
      } else if (err.message?.includes('Network mismatch')) {
        setTxError('Please switch your wallet network to Stellar Testnet.');
      } else {
        setTxError(err.message || 'Failed to sign transaction.');
      }
    } finally {
      setSigning(false);
    }
  };

  return (
    <div>
      {error && <p className="error">Wallet Error: {error.message}</p>}
      {txError && <p className="error">Tx Error: {txError}</p>}
      {!isConnected ? (
        <button onClick={() => connect('freighter')} disabled={isConnecting}>
          {isConnecting ? 'Connecting Wallet...' : 'Connect Freighter'}
        </button>
      ) : (
        <div>
          <p>Connected Key: {publicKey}</p>
          <button
            onClick={() => handleSignSafely('AAAA...')}
            disabled={signing}
          >
            {signing ? 'Awaiting Signature...' : 'Sign Sample Tx'}
          </button>
        </div>
      )}
    </div>
  );
}
```

## 2. useStellarBalances

Tracks XLM and native/custom Stellar token balances for a given public key with reactive updates and optional polling.

### Signature & Inputs

```typescript
export interface BalanceOptions {
  horizonUrl?: string;
  autoRefresh?: boolean;
  refreshIntervalMs?: number;
}

export interface AssetBalance {
  asset_type: 'native' | 'credit_alphanum4' | 'credit_alphanum12';
  asset_code?: string;
  asset_issuer?: string;
  balance: string;
  limit?: string;
}

export function useStellarBalances(
  publicKey: string | null,
  options?: BalanceOptions
): {
  balances: AssetBalance[];
  loading: boolean;
  error: Error | null;
  refresh: () => Promise<void>;
};
```

### Error Scenarios & Edge Cases

- **Unfunded Account (Horizon 404)**: When a new public key is generated but has not received initial XLM funding. The hook catches Horizon 404 and returns `balances: []` with an `isUnfunded: true` helper rather than throwing a hard network exception.
- **Malformed Public Key**: Invalid G-address formatting results in an instant validation error before making HTTP queries.
- **Horizon Rate Limit (429)**: Exceeding network rate limits pauses auto-polling with exponential backoff.

### Race Condition & Unmount Handling

- **Race Condition**: Rapid changing of `publicKey` prop cancels inflight HTTP fetches using `AbortController`. Out-of-order Horizon HTTP responses for previously queried addresses are discarded.
- **Unmount Behavior**: Polling timers (`setInterval`) and active `fetch` requests are terminated during `useEffect` cleanup.

### Worked Edge Case Example

```tsx
import React from 'react';
import { useStellarBalances } from '@/hooks/useStellarBalances';

export function UserBalanceDisplay({
  accountId,
}: {
  accountId: string | null;
}) {
  const { balances, loading, error, refresh } = useStellarBalances(accountId, {
    autoRefresh: true,
    refreshIntervalMs: 10000,
  });

  if (!accountId) return <div>No account provided.</div>;
  if (loading && balances.length === 0) return <div>Loading balances...</div>;

  if (error) {
    return (
      <div>
        <p className="error-box">Failed to fetch balances: {error.message}</p>
        <button onClick={refresh}>Retry</button>
      </div>
    );
  }

  if (balances.length === 0) {
    return <div>Account {accountId} is unfunded or has 0 assets.</div>;
  }

  return (
    <ul>
      {balances.map((b, idx) => (
        <li key={idx}>
          {b.asset_type === 'native' ? 'XLM' : b.asset_code}: {b.balance}
        </li>
      ))}
    </ul>
  );
}
```

## 3. useStellarPayment

Helper hook to construct, simulate, and submit Stellar payment operations.

### Signature & Inputs

```typescript
export interface PaymentParams {
  destination: string;
  amount: string;
  assetCode?: string; // Defaults to native XLM
  assetIssuer?: string;
  memo?: string;
}

export function useStellarPayment(options?: {
  horizonUrl?: string;
  networkPassphrase?: string;
}): {
  buildPaymentXDR: (
    fromPublicKey: string,
    params: PaymentParams
  ) => Promise<string>;
  submitPayment: (
    signedXdr: string
  ) => Promise<{ hash: string; ledger: number }>;
  submitting: boolean;
  error: Error | null;
};
```

### Error Scenarios & Edge Cases

- **Insufficient Reserve**: The sending account does not maintain the minimum required Stellar base reserve (0.5 XLM per entry + base reserve).
- **OpNoDestination**: Sending custom tokens or XLM to a destination account that does not exist and needs a `createAccount` operation instead.
- **Double Submit**: User double-clicks the pay button. Guarded by internal `submitting` status flag.

### Race Condition & Unmount Handling

- **Race Condition**: Prevents submission of outdated transaction XDRs if payment parameters are updated while a prior build operation was pending.
- **Unmount Behavior**: Transaction submission to Horizon continues on the server side, but unmounted components avoid invoking post-submit state callbacks.

### Worked Edge Case Example

```tsx
import React, { useState } from 'react';
import { useStellarPayment } from '@/hooks/useStellarPayment';
import { useStellarWallet } from '@/hooks/useStellarWallet';

export function SendPaymentForm() {
  const { publicKey, signTransaction } = useStellarWallet();
  const { buildPaymentXDR, submitPayment, submitting, error } =
    useStellarPayment();
  const [recipient, setRecipient] = useState('');
  const [amount, setAmount] = useState('');
  const [txHash, setTxHash] = useState<string | null>(null);

  const handlePay = async (e: React.FormEvent) => {
    e.preventDefault();
    if (!publicKey || submitting) return;

    try {
      const unsignedXdr = await buildPaymentXDR(publicKey, {
        destination: recipient,
        amount,
      });
      const signedXdr = await signTransaction(unsignedXdr);
      const res = await submitPayment(signedXdr);
      setTxHash(res.hash);
    } catch (err) {
      console.error('Payment failure:', err);
    }
  };

  return (
    <form onSubmit={handlePay}>
      <input
        placeholder="G..."
        value={recipient}
        onChange={(e) => setRecipient(e.target.value)}
      />
      <input
        placeholder="10.0"
        value={amount}
        onChange={(e) => setAmount(e.target.value)}
      />
      <button type="submit" disabled={submitting || !publicKey}>
        {submitting ? 'Processing Payment...' : 'Send XLM'}
      </button>
      {error && <p className="error">Payment Error: {error.message}</p>}
      {txHash && <p className="success">Success! Tx Hash: {txHash}</p>}
    </form>
  );
}
```

## 4. useTrustlines

Query existing asset trustlines and generate change-trust transaction XDRs for user wallets.

### Signature & Inputs

```typescript
export interface Trustline {
  asset_code: string;
  asset_issuer: string;
  balance: string;
  limit: string;
}

export function useTrustlines(
  publicKey: string | null,
  options?: { horizonUrl?: string }
): {
  trustlines: Trustline[];
  hasTrustline: (assetCode: string, issuer: string) => boolean;
  buildChangeTrustXDR: (params: {
    assetCode: string;
    assetIssuer: string;
    limit?: string;
  }) => Promise<string>;
  loading: boolean;
  error: Error | null;
  refresh: () => Promise<void>;
};
```

### Error Scenarios & Edge Cases

- **Lack of Reserve for Trustline**: Account requires an additional 0.5 XLM reserve per trustline. If balance is below minimum, transaction build or submit fails with `op_low_reserve`.
- **Invalid Asset Code / Issuer**: Passing non-existent issuer public keys returns validation error prior to XDR generation.

### Race Condition & Unmount Handling

- **Race Condition**: If a trustline transaction is submitted and confirmed, invoking `refresh()` immediately re-syncs state; pending inflight refreshes are deduplicated.
- **Unmount Behavior**: AbortController handles component unmounting mid-query.

## 5. useSorobanContract

Interact with Soroban smart contracts — simulate contract methods and invoke transactions.

### Signature & Inputs

```typescript
export function useSorobanContract(
  contractId: string,
  options?: { rpcUrl?: string; networkPassphrase?: string }
): {
  simulateContract: (
    method: string,
    args?: Record<string, any>
  ) => Promise<any>;
  invokeContract: (
    method: string,
    args?: Record<string, any>
  ) => Promise<{ hash: string; result: any }>;
  loading: boolean;
  error: Error | null;
};
```

### Error Scenarios & Edge Cases

- **Contract Panic / Host Error**: Contract simulation fails with error code (e.g., storage subkey missing, `require_auth` failure, integer overflow). The hook extracts exact panic message from RPC simulation result.
- **Storage TTL Expiry**: Attempting to interact with an archived Soroban contract instance without restoring instance storage first.

### Worked Edge Case Example

```tsx
import React, { useState } from 'react';
import { useSorobanContract } from '@/hooks/useSorobanContract';

export function ContractCallComponent() {
  const { invokeContract, loading, error } = useSorobanContract(
    'C1234...CONTRACT_ID'
  );
  const [output, setOutput] = useState<string | null>(null);

  const handleExecute = async () => {
    try {
      const res = await invokeContract('deposit', { amount: 500 });
      setOutput(`Tx Hash: ${res.hash}`);
    } catch (err: any) {
      if (err.message?.includes('HostError')) {
        console.error('Soroban VM panic:', err);
      }
    }
  };

  return (
    <div>
      <button onClick={handleExecute} disabled={loading}>
        {loading ? 'Invoking...' : 'Execute Soroban Call'}
      </button>
      {error && <p className="error">Contract Error: {error.message}</p>}
      {output && <p className="output">{output}</p>}
    </div>
  );
}
```

## Summary Matrix of Edge Case Protections

| Hook                    | Primary Edge Case      | Mitigation Strategy                                    |
| ----------------------- | ---------------------- | ------------------------------------------------------ |
| `useStellarWallet`      | User Popup Closure     | Graceful cancellation without infinite state locking   |
| `useStellarBalances`    | Unfunded Account (404) | Catch 404, return empty array with `isUnfunded` flag   |
| `useStellarPayment`     | Double Submission      | Synchronous `submitting` state lock guard              |
| `useTrustlines`         | Low Base Reserve       | Pre-calculate reserve requirements (0.5 XLM per entry) |
| `useSorobanContract`    | VM Panic / Out of Gas  | Parse host error stack & simulation return values      |
| `useSorobanEvents`      | Memory Leak / Polling  | Strict `useEffect` timer cleanup & AbortSignal         |
| `useOfferBook`          | Out-of-Order Pairs     | Input keying and cancellation of inflight queries      |
| `useTransactionHistory` | Rapid Pagination       | Cursor locking during active `loadMore()` operations   |
