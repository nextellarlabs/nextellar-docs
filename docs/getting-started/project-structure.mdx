# Scaffolded Project Structure Walkthrough

Run `nextellar <project-name>` to scaffold a Next.js 16 application. The generated tree depends on the selected template family (`default`, `minimal`, or `defi`) and language (TypeScript by default, or JavaScript with `--javascript`). The walkthrough below reflects six fresh scaffolds from Nextellar CLI 1.1.0 with installation skipped and Git initialization disabled.

---

## Directory Tree Overview

The default TypeScript scaffold has this core layout. `public/` contains the starter's static assets, and the component and Storybook directories contain additional files beyond the representative paths shown here.

```text
my-stellar-app/
├── .nextellar/config.json
├── .storybook/
├── .env.example
├── public/
├── src/
│   ├── app/
│   │   ├── example/[id]/page.tsx
│   │   ├── globals.css
│   │   ├── layout.tsx
│   │   └── page.tsx
│   ├── components/
│   ├── config/networks.ts
│   ├── contexts/
│   ├── hooks/
│   ├── lib/
│   └── locales/en.ts
├── package.json
├── next.config.ts
└── tsconfig.json
```

The six complete file manifests captured from the generated projects are recorded in the #1078 audit at `routes-d/1078-template-tree-capture.mdx`. The lists are tied to CLI 1.1.0 and the scaffold options noted above; optional installation can add `node_modules/` and lockfiles can vary by package manager.

## How the six generated trees differ

All six variants include `.nextellar/config.json`, `.env.example`, a Next.js App Router under `src/app/`, shared UI components, wallet contexts, hooks, and `package.json`. Every variant includes a `.storybook/` configuration and the public starter assets. Exact component and Storybook files differ; see the tree audit for the complete captures.

| Variant                              | Generated structure                                                                                                                                                                                                                                        |
| ------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `default` TypeScript                 | Adds `tsconfig.json`, `next.config.ts`, `src/config/networks.ts`, `src/locales/en.ts`, the full hook/component set, Storybook stories, starter tests, and Docker/Netlify/Vercel deployment files. It does not include a `contracts/` directory by default. |
| `default` JavaScript (`js-template`) | Adds `jsconfig.json`, `next.config.js`, and `.js`/`.jsx` application, hook, and component files. It has no `src/locales/`, starter test directory, or Docker/deployment files. One Storybook balance mock remains `.ts`.                                   |
| `minimal` TypeScript                 | Includes `tsconfig.json`, `next.config.ts`, `src/config/networks.ts`, wallet and balance hooks, `useTransactionHistory`, and a reduced component set. It has no `src/locales/` or contracts.                                                               |
| `minimal` JavaScript (`js-minimal`)  | Includes `jsconfig.json` and `.js`/`.jsx` app, context, wallet, balance, and clipboard files. It omits `src/config/`, `useTransactionHistory`, and TypeScript configuration.                                                                               |
| `defi` TypeScript                    | Includes `tsconfig.json`, the full DeFi and Soroban hook set, generated contract bindings, and Rust contracts in `contracts/counter/` and `contracts/hello_world/`.                                                                                        |
| `defi` JavaScript (`js-defi`)        | Includes `jsconfig.json`, JavaScript app and classic Stellar/DeFi hooks, plus the same Rust contracts and generated TypeScript bindings. It does not include the Soroban React hooks.                                                                      |

The CLI enables contract scaffolding automatically for `--template defi`; the captured DeFi trees therefore contain contracts even without an explicit `--with-contracts` flag. For other families, `--with-contracts` adds the contract overlay.

## What the main directories contain

- **`src/app/`**: Next.js App Router files, including the home page, root layout, global stylesheet, and example route.
- **`src/components/`**: Wallet, balance, transaction, error, loading, and template-specific UI components, with Storybook stories where provided.
- **`src/contexts/`**: Wallet provider/context and shared context exports. The default TypeScript variant also has theme and i18n providers.
- **`src/hooks/`**: Hooks included by that specific template; the six variants do not have identical hook sets.
- **`src/lib/`**: Wallet-kit setup, local storage, result-code helpers, Soroban helpers, and contract bindings where applicable.
- **`.storybook/`**: Storybook configuration, preview setup, and optional mocks.
- **`contracts/`**: Rust contract workspace generated with `defi` or when the contract overlay is requested.

TypeScript variants use `tsconfig.json`, `next.config.ts`, and typed source files. JavaScript variants use `jsconfig.json`, `next.config.js`, and primarily `.js`/`.jsx` source files; generated DeFi bindings and one Storybook mock can remain TypeScript.
