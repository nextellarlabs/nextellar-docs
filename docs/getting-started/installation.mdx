# Installation

Get started with Nextellar in under 2 minutes. No global installation required!

## Prerequisites

Before you begin, ensure you have:

- **Node.js** 20.18.0 or later (Node >= 20) ([Download](https://nodejs.org/))
- **npm**, **yarn**, or **pnpm** package manager
- **Git** for version control (optional but recommended)

### Check Your Node Version

```bash
node --version
# Should output v20.18.0 or higher
```

### Verify Your Setup

Run the doctor check before scaffolding, or any time you need to confirm that your local machine still matches the CLI requirements:

```bash
npx nextellar doctor
```

A healthy setup should report the required runtime and tooling checks:

```text
Nextellar Doctor

✔ Node.js         v20.18.0 (>= 20.0.0 required)
✔ npm             v10.8.2
✔ Git             available
✔ Stellar RPC     reachable
```

If the doctor reports a failed required check, fix that item before creating the project. Optional warnings can be handled later, but required runtime and package-manager checks should be clean first.

## Quick Install

The fastest way to create a Nextellar project is with `npx` (no global installation needed). This keeps the command current without adding a global package to your machine:

```bash
npx nextellar my-stellar-app
```

## Package Manager Matrix

Nextellar supports all major package managers. The CLI auto-detects your package manager, or you can explicitly choose one:

| Package Manager | Create Command                                | Install Dependencies | Run Dev Server | Run Build       | Run Doctor              |
| --------------- | --------------------------------------------- | -------------------- | -------------- | --------------- | ----------------------- |
| **npm**         | `npx nextellar my-app`                        | `npm install`        | `npm run dev`  | `npm run build` | `npx nextellar doctor`  |
| **yarn**        | `npx nextellar my-app --package-manager yarn` | `yarn install`       | `yarn dev`     | `yarn build`    | `yarn nextellar doctor` |
| **pnpm**        | `npx nextellar my-app --package-manager pnpm` | `pnpm install`       | `pnpm dev`     | `pnpm build`    | `pnpm nextellar doctor` |
| **bun**         | `npx nextellar my-app --package-manager bun`  | `bun install`        | `bun dev`      | `bun run build` | `bunx nextellar doctor` |

### Explicit Package Manager Selection

```bash
# npm (default if package-lock.json exists)
npx nextellar my-app --package-manager npm

# yarn (default if yarn.lock exists)
npx nextellar my-app --package-manager yarn

# pnpm (default if pnpm-lock.yaml exists)
npx nextellar my-app --package-manager pnpm

# bun (default if bun.lockb exists)
npx nextellar my-app --package-manager bun
```

The `--package-manager` flag accepts: `npm`, `yarn`, `pnpm`, `bun`

### Lockfile Detection

Nextellar automatically detects your package manager by checking for lockfiles in the current directory:

- `package-lock.json` → npm
- `yarn.lock` → yarn
- `pnpm-lock.yaml` → pnpm
- `bun.lockb` → bun

If no lockfile is found, it defaults to `npm`.

### Verified Commands

All commands in the matrix above have been verified with:

- Nextellar CLI 1.0.4+
- Node.js 20.18.0+
- Each package manager's latest stable version

### Alternative: Global Installation

If you plan to create multiple projects and want a shorter command, you can install Nextellar globally. Keep it updated when the CLI releases new templates or checks:

```bash
npm install -g nextellar
nextellar my-stellar-app
```

## CLI Options

Customize your project during scaffolding:

### Basic Usage

```bash
npx nextellar <project-name> [options]
```

### Available Options

| Option                   | Description                  | Default                |
| ------------------------ | ---------------------------- | ---------------------- |
| `--typescript`           | Generate TypeScript project  | `true`                 |
| `--skip-install`         | Skip dependency installation | `false`                |
| `--package-manager <pm>` | Choose npm, yarn, or pnpm    | Auto-detected          |
| `--horizon-url <url>`    | Custom Horizon endpoint      | Testnet                |
| `--soroban-url <url>`    | Custom Soroban RPC endpoint  | Testnet                |
| `--wallets <list>`       | Supported wallet adapters    | Auto-detects installed |
| `--install-timeout <ms>` | Installation timeout         | 1200000 (20 min)       |

### Examples

**Create with custom package manager:**

```bash
npx nextellar my-app --package-manager pnpm
```

**Skip installation (install later):**

```bash
npx nextellar my-app --skip-install
cd my-app
npm install
```

**Configure for mainnet:**

```bash
npx nextellar my-app --horizon-url https://horizon.stellar.org
```

**Select specific wallets (custom selection):**

```bash
npx nextellar my-app --wallets freighter,xbull
# See [Wallet Configuration](/docs/cli/flags#wallet-configuration-wallets) for defaults and all supported adapters
```

## Running Your Project

After installation completes:

```bash
cd my-stellar-app
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser. You should see the Nextellar starter page with a wallet connect button!

## Verify Installation

After scaffolding, run
px nextellar doctor again if your environment changed, then test that the generated app works:

1. **Development server starts**: `npm run dev` should run without errors
2. **TypeScript compiles**: No type errors in the console
3. **Wallet connection works**: Click "Connect Wallet" button
4. **Hot reload works**: Edit `src/app/page.tsx` and see changes instantly

Need help? Jump to [Troubleshooting](#troubleshooting).

## Troubleshooting

### Installation fails during scaffolding

If `npx nextellar my-stellar-app` stops while installing dependencies, retry manually from the generated folder:

```bash
cd my-stellar-app
npm install
```

Fixes:

- Slow network or registry timeouts: `npx nextellar my-stellar-app --install-timeout 3600000`
- npm registry issues: `npm config set registry https://registry.npmjs.org/`
- Disk or quota issues: free at least 500MB before retrying

### Unsupported Node version

If the scaffold fails before install, confirm your Node version:

```bash
node --version
```

Fixes:

- Update to Node.js 20.18.0 or later.
- Use a node version manager like `nvm` or `fnm`.

### Port 3000 already in use

If `npm run dev` fails because the port is occupied:

```bash
npm run dev -- -p 3001
```

Fix:

- Start the app on a different port with `-p <port>`.

### TypeScript or build errors after install

If `npm run build` reports TypeScript or type-check errors:

```bash
npm run build
```

Fixes:

- Confirm dependencies installed correctly: `rm -rf node_modules package-lock.json && npm install`
- Re-run the scaffold command with the same package manager used in the project

### Module not found or dependency resolution issues

If a dependency is missing after installation:

```bash
rm -rf node_modules package-lock.json
npm install
```

Fixes:

- Clear the package cache and reinstall dependencies
- Confirm the project was created with your expected package manager
