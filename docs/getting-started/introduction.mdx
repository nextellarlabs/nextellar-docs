# Welcome to **Nextellar**

## Build Stellar-Powered Applications with Speed and Confidence

Welcome to **Nextellar**, a modern developer toolchain designed to help you build Stellar-powered applications with speed, consistency, and confidence. Nextellar provides a **one-step CLI**, **opinionated scaffolding**, and **first-class Stellar integration** so you can focus on product development instead of boilerplate setup.

Whether you're building a wallet, a payment experience, a dApp, or a full-scale production application, Nextellar gives you a clean, extensible foundation powered by:

- **Next.js 16** (App Router with Turbopack)
- **TypeScript 5**
- **React 19**
- **Stellar SDK** and **Stellar Wallets Kit**
- **Tailwind CSS 4**
- **Framer Motion** for animations
- **Zustand** for state management
- **8 Production-Ready React Hooks**

Nextellar reduces the time developers spend configuring tools, managing dependencies, and wiring up blockchain integrations. With a single command, you're ready to build.

## Architecture at a Glance

Nextellar sits between your application code and the Stellar network, wiring the CLI-scaffolded project, React hooks, and wallet/SDK layers together so you never touch raw Horizon or Soroban RPC calls directly:

```text
flowchart TB
    CLI["Nextellar CLI<br/>Scaffolding & Config"]
    APP["Your Next.js Application"]
    HOOKS["8 React Hooks<br/>useStellarWallet · useStellarPayment · useStellarBalances · ..."]
    CONTEXT["WalletProvider Context"]
    WALLETS["Stellar Wallets Kit<br/>Freighter · Albedo · Lobstr · xBull · Hana"]
    SDK["Stellar SDK<br/>Horizon · Soroban RPC"]
    NETWORK["Stellar Network"]

    CLI --> APP
    APP --> HOOKS
    HOOKS --> CONTEXT
    CONTEXT --> WALLETS
    CONTEXT --> SDK
    WALLETS --> NETWORK
    SDK --> NETWORK
```

The CLI generates your project structure once, up front. From there, the React hooks are the primary interface your components use — they read configuration from `WalletProvider` and delegate to the Stellar Wallets Kit for signing and to the Stellar SDK for Horizon and Soroban RPC calls, both of which talk to the Stellar network.
