# Hosted API

<Note type="warning">
  **Roadmap — not yet available.** Nextellar currently has no hosted API
  endpoint. The CLI bootstraps your project locally; the only outbound network
  call it makes is an opt-in telemetry ping. A hosted API is on the roadmap but
  has not shipped.
</Note>

## What is planned

- A REST / GraphQL surface that mirrors the React-hook API, usable from
  server-side or non-React environments.
- Authentication via API keys tied to a Nextellar account.
- Rate-limited access to Stellar Horizon and Soroban RPC through a managed
  proxy, so you do not need to expose third-party endpoints directly.

### Authentication (planned)

Requests to the hosted API will be authenticated with an API key issued to
your Nextellar account, sent as a bearer token:

```bash
curl https://api.nextellar.dev/v1/balances/GA5Z... \
  -H "Authorization: Bearer <your-api-key>"
```

Keys will be scoped per project and revocable from the account dashboard.
There is no API key to generate today — this shape is not final until the
API ships.

### Rate limits (planned)

Requests will be rate-limited per API key to keep the managed Horizon/Soroban
proxy fair for all users. The plan is a sliding-window limit with the
remaining quota surfaced in response headers, for example:

```text
X-RateLimit-Limit: 60
X-RateLimit-Remaining: 42
X-RateLimit-Reset: 1717000000
```

Exceeding the limit will return `429 Too Many Requests`. Exact limits and
tiers have not been finalized and will be published when the API ships.
